## 誰に聞くか（散らし方）

追い質問をしない経路なので、**深掘りの代わりに人を散らして精度を出す。**

| 軸 | 散らしたい内容 | 埋まり具合 |
| --- | --- | --- |
| 確認画面 | **使った人**／使わなかった人 | **0/3**（3 人とも未使用）。**未達（最優先）** |
| 調理か否か | 調理担当（検便提出済み）／**非調理** | 調理 3 人 → 非調理 **0/3**。**未達** |
| 学年 | 3・4 年（調理責任者になりうる）／1・2 年 | 当時 3 年 2 人・当時 2 年 1 人 → 1 年 **0/3**。**未達** |
| 日程の制約 | **希望を絞った人**／全日程 OK の人 | 3 人とも「全部 OK」→ 希望を絞った人 **0/3**。**未達** |
| 提出タイミング | 締切内／**締切を過ぎて出した人（5 人いた ◎）** | 締切内 1 人・不明 1 人・**締切後 1 人** → **1/3 で埋まった**（3 人目） |
| 事後申告 | **「希望と違う」と連絡した人（1〜2 人いた ◎）**／しなかった人 | 3 人ともしていない → **0/3**。**未達** |
| 立場 | 幹部・代表／**一般のメンバー** | 3 人とも運営側（幹部・幹部の手伝い・代表）→ 一般のメンバー **0/3**。**未達**（3 人目で顕在化） |

→ **3 人かけて埋まった軸は「締切後」の 1 本だけ** (1/3)。残りはすべて **0/3** のままである。
→ 4 人目以降の最優先は **「全員分見れちゃうんだ」と作る側に言った人**。
その発言ができる時点で**確認画面を実際に開いている** ◎ ため、**仮説 7 に答えられる唯一の既知の層**。
次いで **非調理 / 1 年 / 日程に制約があって希望を絞った人**。
**3 人続けて同じ層（調理可・全日程 OK・運営側）に当たっている**ため、
**4 人目以降の相手の選び方は別 issue に切り出す**（issue #34）。

## 送る文（コピペ用）

```
去年の学祭シフト作成を引き継げる形にするついでに、シフト作る人の負担とシフトの質を今年はもうちょっとマシにしたくて10個の質問だけ付き合ってほしい！！
シフト入る側がどうだったのか全然分かってないから、思い出せる範囲で教えてほしい。
分かるやつだけでいいし、正直に「面倒だった」とかでもわかるだけありがたい。

1. 希望のフォーム、いつ・どこで（スマホ？）出した？ どのくらい時間かかった？
   あと、入力してて止まったところとか面倒だったところあった？

2. 希望の時間を決めるとき、何を見ながら決めた？（バイトのシフト、授業、他の予定とか）

3. 「一緒に組めたら嬉しい友達」の欄、何を書いた？ 書くときどうなると思って書いた？

4. 出した後に「あれ何て書いたっけ」ってなったことある？ そのときどうやって確認した？

5. シフト出たあと、自分の出番は LINE の画像とサイトのどっちで見た？ なんでそっちだった？
   あと、画像から自分の名前を探すのって実際どうやってた？（拡大した / スクショ撮った / メモし直した とか）

6. 自分の出番、何回くらい見直した？ いつ見た？（前日とか当日の朝とか）

7. 自分の希望を確認できる画面、使った？ 何を確認したくて開いた？
   使ってみて良かったところと、逆に微妙だったところがあれば両方教えて。

8. 出した希望と違うコマ、入ってた？ そのとき言った？ 言わなかった？
   その理由も教えてほしい（言いづらかった / 別にどうでもよかった / 気づかなかった とか）

9. シフトの量、他の人と比べてどうだった？ そもそも他の人と比べた？

10. シフト周りで一番面倒だったのどこ？ 逆に、これは別に困ってないってところある？
```

### 見出しと順序（手順 4。送る文には出さない）

**① 導入ブロック**（冒頭の 3 行）が欠番を埋めている部分。何のために聞くか／**問数を明示**／
**「分かるやつだけでいい」「正直に面倒だったでいい」**。**自分の苦労は言わない。自作したもの（確認サイト・希望確認画面）も擁護しない。**

| 見出し | 質問 | 並びの役割 |
| --- | --- | --- |
| ① 導入 | （冒頭 3 行） | 導入 |
| ② 希望を出すまで | 1・2・3 | 事実（クローズド寄り） |
| ③ 出したあと | 4 | 行動 |
| ④ シフト表を見る | 5・6 | 行動 |
| ⑤ 確認画面 | 7 | 行動 → 判断 |
| ⑥ 希望とのズレ・量 | 8・9 | 判断・感情 |
| ⑦ まとめ | 10 | 背景・優先順位（オープンエンドの本命） |

一発送信なので、**1 問に「何をしたか」と「なぜそうしたか」を両方入れてある**（手順 0 の例外）。
背景は薄く、Q9（他人と比べたか）と Q10 で拾う形にしている。

### 数えて分かったこと

- **仮説 4 は 3 人続けて非該当。** 控えの需要は、この 3 人には存在しない。
  ただし 3 人目で初めて「**あれ何て書いたっけ**」に**なった** → **見返したくなること自体は起きる**。
  困らなかった理由は **3 人とも「全日程 OK だから」で同じ** → **希望を絞って出した人に当たるまで判定できない**
- **仮説 7 は非該当ですらない。** 3 人とも未使用で、**そもそも答えられる相手を選べていなかった**（散らし方の失敗であって、質問の失敗ではない）。
  **3 人続けて同じ失敗をしている**
- **仮説 3・5・6・10 は 2:1 に割れた。** 5 人未満なので判定できない。**人数を足す**のが先。
  ただし 5（媒体）と 10（一番の摩擦）は**向きが逆転した** — 5 は画像 2:1、10 は**当日運用 2 : 提出 1**
- **仮説 1a・2 は 3/3 で非該当。** 作る側が力を入れた部分（フォームの作り込み）は届いていない。
  **締切後に出した人（3 人目）ですら「時間はほぼかからなかった」**
- **数えられる母数は 3。** 器としては成立しているが、**判定には 5〜6 人**が要る

→ ここは**仮説ごと**の該当数。**質問ごと**の「揃った／割れた」は下の「回答を並べる」節にある（同じ 3 人を別の切り口で数えているので、片方だけを見て判定しない）。

## パイロット（1 人目）で分かったこと

- **10 問すべてに回答が返ってきた。** 問数は一発送信の上限としてちょうどよい
- **Q7（確認画面）が 3 人続けて「使ってない」で空振り。** 質問の作りではなく**相手の選び方**の問題
- **Q9 が 1 人目では「幹部でずっといたので何とも」、3 人目では「比べてないです」で取れなかった。** 比較していない層には成立しない（**2/3**）
- **Q10 に「面倒」ではなく改善案が返ってきた**（2 人目）。想定外の層（当日の運用）が拾えたので、この形は維持する。
  **3 人目も Q10 で当日の運用を挙げた**（交代・引き継ぎ）→ この問いは**提出以外を拾う口**として機能している
- **Q5 の「なんでそっちだった？」が 3 人目で初めて答えられた。** 1・2 人目は媒体だけを答えて理由を落としていた →
  **問いの作りではなく、答えの粒度が人によって振れる**。**一発送信では理由が落ちることがある**と分かった

**質問は 1〜3 人目で変えていない**（同じ 10 問）。比較可能性を優先したため。
**4 人目から変える場合は、どこをどう変えたかをこのファイルに残す**（手順 6）。

## 回答（聞いたあとに追記する）

**回答は要約せず、相手の言葉のまま置く。** 読み取った結論は「埋まったこと／残った空白」列に分け、

**立場ごとに 1 本なので、入る側のマップの ◎ はそのまま入る側の証言を指す**（旧 `◎入` は廃止。issue #30）。
