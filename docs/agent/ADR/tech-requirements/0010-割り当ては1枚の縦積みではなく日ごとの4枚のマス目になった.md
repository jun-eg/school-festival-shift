# ADR tech-requirements-0010: 割り当ては 1 枚の縦積みではなく、日ごとの 4 枚のマス目になった

- **Status**: 有効
- **Date**: 2026-09-23
- **対象**: `docs/tech-requirements.md` — **2 の「何で動かすか」** ／ **8 の 1**
  ／ `src/sheet-layout.js`（シートの構成）／ `src/README.md`（「シートは 8 枚である」）
- **出典**: **前回の配布物 ◎**（2026-09-23。`11月1日シフト表` 〜 `11月4日シフト表` の 4 枚が提示された）
  ／ **`data/前回の確定シフト-モック-0N.json` の実測**（→ `scripts/前回のシフト表.mjs`）
  ／ [issue #213](https://github.com/jun-eg/school-festival-shift/issues/213)

## それまでの結論

**8 の 1 が、シートを 5 枚と書いていた。**

> シートは**条件入力／回答／割り当て／検証結果／指標**

**`割り当て` は 1 枚で、列は `日 / 開始 / 終了 / 役割 / 学籍番号 / 氏名` だった**（[issue #135](https://github.com/jun-eg/school-festival-shift/issues/135)）。
**1 行 ＝ 1（人・枠・役割）の縦積みである。**

**配布形の形は、5 の #9 が「前回の配布物と同じ粒度」としか書いていなかった。**
**粒度は書いてあったが、並べ方は書いていなかった。**

## 何が起きたか

**前回の配布物そのもの ◎ が出てきた。****形は縦積みではなかった。**

| | 縦積み（それまで） | 配布物 ◎ |
| --- | --- | --- |
| **枚数** | 1 枚 | **4 枚（1 日 1 枚）** |
| **行** | 1（人・枠・役割） | **人** |
| **列** | 日 / 開始 / 終了 / 役割 / 学籍番号 / 氏名 | **30 分枠** |
| **セル** | — | **役割名 1 つ**（役割ごとに色 ◎） |

**3 つが、記録の側から裏付いた。**

**1. 記録がこの形にそのまま載る。** `data/` の確定シフト 4 本を敷き直すと、
**行数が記録の `results` の件数と一致する**（`25 / 21 / 36 / 11`。→ `scripts/前回のシフト表.mjs`）。

**2. 行の鍵は学籍番号であって、氏名ではない。**
**同じ仮名に学籍番号が 2 つ付いている組が 4 つある ◎**（→ [`0004`](0004-同じ仮名の4組は別人で確定シフトの実人数は40だった.md)）ので、
**氏名で引くと `0 / 3 / 3 / 2` 行が潰れる。****配布物 ◎ も、同じ氏名を別々の行に描いている。**

**3. 1 セルに入るのは役割 1 つである。**
**記録には、1 セルに 2 役割になるセルが 2 つある** — `2025-11-02` の `森田咲良`（`ECL2482775`）が
`10:00-11:00 調理` と `10:00-12:00 列整理` の両方に入っている ◎。**配布物 ◎ でも、片方しか描かれていない。**

**縦積みでは、入る側の読み方 2 つがどちらも成立しない**（→ `docs/journey/入る側.md`）。

| 改善機会 | 縦積みでは | マス目では |
| --- | --- | --- |
| **9**「個人が自分の出番を探す手間が残る ◎ (3/5)」 | 1 人の 1 日が 20〜30 行に散る | **自分の行を 1 本見れば出る** |
| **17**「他人がいまどこにいるかを知るために見られている ◎ (1/5)」 | 1 つの枠が 5〜8 行に散る | **その時刻の列を縦に見れば出る** |

## 新しい結論

**シートは 8 枚である。****割り当ては日ごとの 4 枚に、従来のシフト表の形で載る。**

- **4 枚の名前は、希望時間 4 設問のラベル ◎ と同じ 4 つ**（`準備日` ／ `学祭1日目` ／ `学祭2日目` ／ `片付け`）。
  **値は `src/sheet-layout.js` の `dayLabels` 1 か所である** — **フォームの側もここを見る**
- **行は人（学籍番号で引く）、列はその日の 30 分枠、セルは役割名 1 つ**
- **行の並びは学籍番号の昇順**（入力から決まる。→ 6 の #3）
- **列に当てるのは位置ではなく、見出しに書いてある時刻そのものである** — 位置で当てると、
  営業時刻を動かしたときに前の周の役割が別の枠へ黙って移る
- **氏名は回答から引いて、見出しの列に置くだけである。****生成は氏名を 1 度も見ない**（→ 5 の #1）

## 影響

| 何が | どう動いたか |
| --- | --- |
| **8 の 1** | **シートが 5 枚から 8 枚になった。**作業の順序そのものは動いていない |
| **2 の「何で動かすか」** | 「同じ 1 ファイルの中のシートとして並ぶ」に**枚数**が付いた。**手直しがスプレッドシートの上であること自体は動いていない** |
| **5 の #8**（セルを 1 つ書き換える） | **判定が素直になった。****1 セル ＝（その人・その枠）で、書き換えるのは役割名 1 つ**である。縦積みでは「行を消す／足す」で、セル 1 つの書き換えにならなかった |
| **5-4**（未充足の名指し） | **動いていない。****空のセルは「その人がその枠に入っていない」だけで、人数が足りないことを意味しない。**名指しは `検証結果` が持つ |
| **規則・型・生成・数える側** | **1 つも動いていない。** 敷き方は `src/assignment-grid.js` が別に持ち、コアが受け渡す行の形（`日 / 開始 / 終了 / 役割 / 学籍番号 / 氏名`）はそのままである |
| **M2** | **数は動いていない**（違反 0 件・名指しされていない未充足 0 件）。生成の経路に触っていない |

**決めていないことが 2 つ残った**（→ [#213](https://github.com/jun-eg/school-festival-shift/issues/213)）。

- **4 枚目の名前。** 起票時の言葉は `片付け日` だが、**設問の題 `11月4日(片付け)` は記録からの転記 ◎**（→ 4-1 の #9）なので、
  **記録の側（`片付け`）のままにした。**動かすならラベルごと動かす
- **営業時刻を動かしたあとの手直しの扱い。****いまは「いまの枠に無い見出し」として名指しして止まる。**
  **名指しで返す形に変えるのは [#156](https://github.com/jun-eg/school-festival-shift/issues/156)（固定を入力に積む）である**（→ 5-3）
