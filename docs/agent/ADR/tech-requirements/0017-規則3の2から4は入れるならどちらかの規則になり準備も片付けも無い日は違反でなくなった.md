# ADR tech-requirements-0017: 規則 3 の ②〜④ が「必ず入れる」から「入れるなら、どちらに入れるか」に変わった — **準備も片付けも無い日は違反でなくなった**

- **Status**: 有効
- **Date**: 2026-09-24
- **対象**: `docs/tech-requirements.md` — **3 の規則 3**（表の ②〜④ と「規則 3 が乗る先」）／ **5-3**（規則 3 で手直しを外す所）／ **5-4**（違反に数える規則 3 の範囲）／ **5-5**（「準備・片付けをどこに置くか」「置かないほうに倒す所」「規則 3 の端」「散らし」）／ **7**（帯が 0 枠の日）
  ／ `src/count-violations.js`（`prepCleanupDetail`）／ `src/generate.js`（`whyPrepCleanupBreaks`・`addPrepCleanup`・`fillPrepCleanupDemand`・`releaseFixesBreakingRule3`・`rule3Gap`）／ `src/README.md` ／ `scripts/まとまりと散らし.mjs`・`scripts/まとまりと散らしの宣言.json`
- **出典**: [issue #280](https://github.com/jun-eg/school-festival-shift/issues/280)（検証結果に `準備・片付け: 午後だけ入っているので、片付けだけにしてください（境目 12:00。今：準備なし／片付けなし）` が赤で出た）

## それまでの結論

**規則 3 の ②〜④ は義務の形だった。**

> ② **午前だけ → 準備**に入れる<br>③ **午後だけ → 片付け**に入れる<br>④ **両方ある → 片方だけ**に入れる

**数える側**は、店の役割に就いた人が準備にも片付けにも入っていなければ、**② ③ ④ の違反として赤で出していた**
（[#258](https://github.com/jun-eg/school-festival-shift/issues/258) が水色にしたのは `今：準備あり／片付けあり` だけで、「**準備も片付けも無い … これまでどおり赤**」と明記してある）。

**生成**は「破るくらいなら置かない」で、**その日の準備帯・片付け帯に、希望にあって空いている枠が残らない人を店の枠に置かなかった**（5-5 の「置かないほうに倒す所」）。

> **帯を 1 枠も希望していない人は、その日に置けない** — 置けば規則 1 か規則 3 のどちらかが破れる。**その枠は未充足として名指しで残る**

**[`0011`](0011-1枠も置かれない人は散らしではなく規則3で決まっていた.md) は、これで 1 枠も置かれない人が出ていることを数え**
（M2 の入力で学祭 1 日目 8 人・2 日目 12 人）、「**減らすには規則 3 の適用を変えることになる**」として動かさなかった。

## 何が起きたか

**検証結果に `今：準備なし／片付けなし` の規則 3 の違反が赤で出て、「この類の違反は青と決めたはず」と指摘された**（issue #280）。
**色の塗り分けは決めどおりに動いていた** — 問われたのは、**それを違反と読むこと**のほうである。

**上流と記録を突き合わせると、「なし／なし」を崩れた形と読む根拠が無かった。**

1. **作る側の手順が「入れた後で削る」である** ◎ —「**希望時間的に出られる人をとりあえず入れた後、複数日程全体をみて負担が大きくならないように削った**」（→ 4-5）。
   **⑥（偏らせない）で削れば「なし／なし」の人が出る。****手順どおりの結果である。**
   **崩れた形と担当者が言ったのは「両方入っている」のほうである**（「**削り忘れ**」◎ → [`0003`](0003-準備と片付けの規則が降りた先から戻りM2の数えに入った.md)）
2. **記録にもいる** — **店の役割はあるのに `準備` も `片付け` も無い人が、11月2日に 5 人・11月3日に 9 人**（[`data/前回の確定シフト.md`](../../../data/前回の確定シフト.md)）
3. **準備・片付けは需要になった**（[`0009`](0009-準備と片付けを需要に立て規則3の5が当たらなくなった.md)）。**人数が足りるかは未充足が名指しする。**
   **規則 3 で「全員に必ず 1 枠」を求めなくても、足りなければ未充足の行に出る**
4. **「なし／なし」は負担が軽いだけである。** README の「**赤**は必ず直す違反、**青**は公平さを欠くものの、そのままでも問題のない違反」で言えば赤ではない。
   **偏りは ⑥ の話で、⑥ の線はまだ無い**（→ 9 の △ 5）

## 新しい結論

**②〜④ は「入れるなら、どちらに入れるか」の規則である。****準備にも片付けにも入っていない日は違反にしない。**

| その日の店の割り当て | 準備 | 片付け | それまで | いま |
| --- | --- | --- | --- | --- |
| 午前だけ | あり | なし | 違反でない | 違反でない |
| 午前だけ | **なし** | **なし** | **違反（赤）** | **違反でない** |
| 午前だけ | なし | あり | 違反（赤） | 違反（赤）— 逆の方 |
| 午前だけ | あり | あり | 違反（水色） | 違反（水色）— #258 |
| 午後だけ | 午前だけの行の、準備と片付けを入れ替えたもの | | | |
| 午前も午後も | どちらか一方 | | 違反でない | 違反でない |
| 午前も午後も | **なし** | **なし** | **違反（赤）** | **違反でない** |
| 午前も午後も | あり | あり | 違反（水色） | 違反（水色）— #258 |

**⑤（どちらも無い → 入れない）は 0009 のまま当たらない。****⑥ の線はまだ引かない**（→ 9 の △ 5）。

**生成は、向きだけを守る。**

- **帯を 1 枠も希望していない人も店に置く。****その人は準備にも片付けにも入らない**
- **3 段目**は、入れられる人にはこれまでどおり入れる（**需要の残っている枠を先に取り、無ければ 1 枠**）。**入れる向きの帯に空きが無い人は飛ばす**（それまでは内部エラーで止まる所だった）
- **4 段目**は、**3 段目で入らなかった人を逆の帯に入れない**（午前だけの人を `片付け` に、午後だけの人を `準備` に置かない）。
  **issue #280 は「4 段目の見張りが今もかかっているはず」と見込んでいたが、かかっていなかった** —
  **4 段目は「もう片方の帯に入っていないか」しか見ておらず、それまでは 3 段目で全員に 1 枠入っていたので見張りが要らなかった。**
  **見張りを外すと、午前だけの人が `片付け` に入り赤が 1 件出ることを検査で確かめた上で、向きの見張りを足した**
- **手直しを外すのは、向きが合わないときだけである**（5-3）。**帯に空きが無いだけの日は外さない**

**店の役割の未充足は 0 になった**（会計の 2 人が埋まった）。**あと何人の合計は 6 人増えた** — 増えたのは準備・片付けである。

- **店の役割だけの 22 人のうち 20 人は、その日の準備帯にも片付け帯にも候補が無い**（**それまでは置けなかった人である**）
- **残る 2 人は学祭 2 日目で、午前だけ店に入り、片付け帯にしか候補が無い。****それまでの生成は、この 2 人を午前の店に置かなかった**
  （置けば規則 3 が破れるので、片付けと向きの合う午後か、店に置かずに 4 段目の片付けに回っていた）。**いまは午前の店に置かれ、向きが合わないので片付けには入らない**
- **残りの差は、店の枠を分け合う人が増えて、誰が午前・午後に入るかが組み変わったぶんである**

**「向きの合う側の半日に寄せる」を生成に足せば、2 人ぶんは戻る見込みがある。****この ADR では足していない** —
規則ではなく置き方の好みで、**同点の順序（5-5 の「枠の中で誰を採るか」）に何を足すかの判断になる**ので、別に扱う。

**実機はまだ見ていない。**
