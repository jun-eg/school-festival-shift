# ADR tech-requirements-0001: 必要人数の不足が「違反」に数えられていて、M2 の合格の線が永久に出ない形になっていた

- **Status**: 有効
- **Date**: 2026-09-19
- **対象**: `docs/tech-requirements.md` — 7 の M2 の行 ／ 5 の #6（新設した 5-4 が受けた）
- **出典**: `docs/design-doc.md` 6 スコープ内 5「満たせない枠は**埋まらないまま名指しで残す**（黙って埋めない）」 ／ 同 7 M2「**違反が 0 の案が出る**。埋まらない枠は名指しで残っている」

## それまでの結論

7 の M2 の「何を数えるか」が、こう書かれていた。

> **規則 1〜6 の違反件数**（検便 ◎・学年 ◎・時間 ◎・**指定枠 ◎・必要人数 ◎**・準備／片付け ◎）／ **未充足の枠のうち名指しされていないもの**

合格の線は「**違反 0 件**かつ**名指しされていない未充足枠 0 件**」。
**必要人数 ◎ と指定枠 ◎ が、違反の側にも未充足の側にも立っていた。**

## 何が起きたか

**生成方式を決める作業（issue #95）で、この 2 つが同時に満たせないことが分かった。**

上流は「**違反が 0 の案が出る**」と「**満たせない枠は名指しで残す**」を並べて書いている。
必要人数の不足を違反に数えると、**枠が 1 つでも埋まらなかった時点で違反が 1 以上になる**ので、
**「違反 0 かつ未充足を名指し」という状態が原理的に存在しない。**
39 人 ◎ で 88 枠（前回の営業時間 ◎ で刻んだ場合）× 1 枠 8 人 ◎ を埋める以上、未充足が出ない保証はどこにも無い。

**上流の判断は動いていない。** 動いたのは、この文書が持っている**測り方**である。

## 新しい結論

**数える対象を 2 つに分けた**（`docs/tech-requirements.md` 5-4）。

| | 何か | M2 の合格の線 |
| --- | --- | --- |
| **違反** | **置いた人が条件を破っている** — 検便 ◎（規則 5）・学年 ◎（規則 4）・希望の時間の外 ◎（規則 1）・準備／片付け ◎（規則 3）・同じ人が同じ 30 分枠に二重 | **0 件** |
| **未充足** | **人数が足りない** — 必要人数 ◎（5-1 の #2）・委員会の指定枠 ◎（規則 6） | **名指しされていない未充足が 0 件**（**未充足そのものは 0 でなくてよい**） |

**この分け方が、生成方式の選定の入力になった** — 「解なし」で止まる方式が使えないのは、未充足を抱えたまま 1 案を返す必要があるからである（同 6 の #3）。

## 影響

- **7 の M2 の行**を書き直した（何を数えるか・合格の線）
- **5 の #6** の判定を「違反 0 ＋ 人数が足りない枠が全部名指しで出ている」に書き直し、**5-4 を新設**して分け方の原本を置いた
- **8 の 8**（生成を作る）に、違反と未充足の別を書き足した
- **`docs/design-doc.md` は 1 行も動かしていない。** 上流の完了の定義（M2）はそのままで、読み方が確定しただけである
