# ADR dev-env-0001: 配布は `src/` の 20 ファイルを貼る形ではなく、ビルドが出す `dist/` の 4 つを貼る形になり、版（タグ）が画面から読めるようになった

- **Status**: 有効
- **Date**: 2026-10-25
- **対象**: [`CONTRIBUTING.md`](../../../../CONTRIBUTING.md)（「手で貼る」・「`clasp push` でもよい」）／ [`src/README.md`](../../../../src/README.md)（「テンプレートの作り方」の手順 3・「clasp を本筋にしない」）／ `.claspignore`（削除）／ [`src/shell/version.ts`](../../../../src/shell/version.ts) ・ [`src/shell/menu.ts`](../../../../src/shell/menu.ts)（項目 5 つ目）／ [`build.mjs`](../../../../build.mjs)
- **出典**: [issue #299](https://github.com/jun-eg/school-festival-shift/issues/299)（親）／ [issue #306](https://github.com/jun-eg/school-festival-shift/issues/306) ／ [#302](https://github.com/jun-eg/school-festival-shift/issues/302)（ES モジュール ＋ esbuild）

## それまでの結論

**テンプレートの作り方は「手で貼る」が 1 本で、貼る物は `src/` の `.js` 18 本と HTML 2 枚の 20 ファイルだった**（[`src/README.md`](../../../../src/README.md) の「テンプレートの作り方」の手順 3）。
**clasp は本筋にせず、手貼りを原本にしていた。** 理由は 4 つあった。

| 理由 | |
| --- | --- |
| 貼るのにインストールが 1 つも要らない | 実機でなぞった結果、ブラウザだけで 4 ファイルが入った（当時のファイル数） |
| `.clasp.json` がリポジトリに無い | スプレッドシートごとに違うので入れない |
| 貼るのは 1 回だけである | テンプレートを作るのは用意する側が 1 回で、繰り返さない作業に道具を増やさない |
| ファイル名が 1 対 1 で対応する | 貼った名前がそのまま付くので、リポジトリの `.js` と Apps Script の `.gs` が名前で突き合わせられる |

**「`src/` のファイルが増えたら、この判断は見直す」と書いていたが、4 つから 16 になっても動かしていなかった。**
**テンプレートのスクリプトがどの commit かを知る手段は無かった。**

## 何が起きたか

[#302](https://github.com/jun-eg/school-festival-shift/issues/302) で `src/` が ES モジュールの TypeScript になり、esbuild が `dist/` に **`main.gs` 1 本・HTML 2 枚・`appsscript.json` の 4 つ**を出すようになった（[`build.mjs`](../../../../build.mjs)）。

1. **貼る物が 20 ファイルから 4 つに変わった。** 手順書 2 本（`CONTRIBUTING.md` と `src/README.md`）と `.claspignore`（`*.test.ts` を外していた）がそのままだと嘘になる
2. **「ファイル名が 1 対 1」が消えた。** `.ts` が `main.gs` 1 本に束ねられ、名前では突き合わせられない
3. **「インストールが 0」は、差し替える側には成り立たなくなった。** ビルドに Node と esbuild が要る（[#300](https://github.com/jun-eg/school-festival-shift/issues/300) ・ [#302](https://github.com/jun-eg/school-festival-shift/issues/302)）。**担当者に要求するものは 0 のままである**（担当者はテンプレートをコピーするだけ）
4. **「貼るのは 1 回だけ」は元から成り立っていなかった。** コードを直すたびにテンプレートを差し替える（[`CONTRIBUTING.md`](../../../../CONTRIBUTING.md)）

## 新しい結論

- **貼る物は `dist/` の 4 つである。** **`dist/` は git に入れない**（貼る前に毎回 `npm run build`）。入れると Node 無しで差し替えられるが、差分のノイズと `src/` との乖離が生まれるので却下した（[#299](https://github.com/jun-eg/school-festival-shift/issues/299)）
- **差し替えの単位はタグである。** タグ（`v<連番>`）を打ち → `npm run build` → 貼る。**タグの無い `dist/` を貼らない。** ビルドは、HEAD にタグがあればそのタグを、無ければ短い SHA を `dist/main.gs` の定数に入れる（タグが無くても止まらない。止めるのは手順の側である）
- **版は担当者の画面から読める。** メニュー「シフト」の末尾「バージョン」を押すと、貼った版が画面の隅に出る。**押さなくても困らない項目で、担当者の操作は増えない**（2 の「担当者がやることの全部」は動かさない）。条件入力の 13 行目の隣には置かなかった — シートの形（[`sheet-layout.ts`](../../../../src/core/sheet-layout.ts)）と保護と `buildTemplate` が動くが、メニューの 1 項目なら関数 1 つで済む
- **clasp は 2 つに分けて書く。**
  - **テンプレートへの差し替え**: 手貼りを原本にする。残る理由は `.clasp.json` がスプレッドシートごとに違い、リポジトリに入れられないことだけである。「インストールが 0」「貼るのは 1 回」「ファイル名が 1 対 1」は落とした。貼る物が 4 つに減ったので、clasp の旨味（20 回貼る手間）も小さい。`clasp push` で上げてもよい（`rootDir` は `dist`）
  - **検証用スプレッドシートへの `clasp push` ・ `clasp run`**: 開発側の本線である（[#307](https://github.com/jun-eg/school-festival-shift/issues/307)）。担当者にもテンプレートにも関係しない
- **`.claspignore` は消した。** `dist/` に 4 つしか無く、除外する物が無い（以前は `*.test.ts` と `*.md` を外していた）

## 影響

- [`CONTRIBUTING.md`](../../../../CONTRIBUTING.md) の「手で貼る」を `dist/` の 4 つ ＋ タグの手順に書き換え、`dist/` を git に入れないと明記した。「`clasp push` でもよい」の `rootDir` を `dist` にした。**今の結論はここが持つ**
- [`src/README.md`](../../../../src/README.md) の「テンプレートの作り方」の手順 3 から「`.js` 18 本」を外し、「clasp を本筋にしない」の表を引き直した（上の 3 行を落とし、4 つ目を「版で突き合わせる」に替えた）
- メニューが 4 項目から 5 項目になった。[`entry.ts`](../../../../src/entry.ts) の一覧に `showVersion` を足し、[`entry.test.ts`](../../../../src/entry.test.ts) が、ビルドが版を定数に埋めること・タグか短い SHA を選ぶこと・メニューの関数が版を出すことを Node の上で確かめる
- **実機の確かめは [#331](https://github.com/jun-eg/school-festival-shift/issues/331) に預けた** — 4 つを貼るだけでメニューが動くか、コピーしたスプレッドシートから版が読めるか。[`src/real-device-log.md`](../../../../src/real-device-log.md) への記録も #331 でやる
