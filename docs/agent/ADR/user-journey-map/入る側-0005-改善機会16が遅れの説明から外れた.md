# ADR 入る側-0005: 「4 人目が締切に遅れたのは他サークルの予定が確定していなかったから」が外れた

- **Status**: 有効
- **Date**: 2026-09-14
- **対象**: docs/journey/入る側.md — ACTION 1・2 / 改善機会 16
- **出典**: [`docs/interviews/01-入る側.md`](../../interviews/01-入る側.md)（4 人目 追い質問⑥）/ issue #42

## それまでの結論

改善機会 16（希望提出の時点で入る側の他予定がまだ確定していない ◎）を、
**4 人目が締切に遅れた理由**としても読んでいた。
4 人目は「迷ったのは時間です。掛け持ちをしていたのでわからなかった」と答えており、
材料が揃わないから出せなかったのだろう、という読みである。

## 何が起きたか

追い質問⑥で、本人は **b（材料が揃わなかった）ではなく a（後回しになった）を選んだ** ◎。

## 新しい結論

**外れ ◎ (1/1)。** **ACTION 2 の詰まり（他サークルの予定が分からず時間に迷う）と、
締切に遅れたことは別の話だった。**

改善機会 16 は **ACTION 2 の観測としては残るが、ACTION 1（遅れの説明）からは外す。**
**b を選んだ人は 1 人もいない**が、3 人目は a/b/c のどれにも答えていないので **(0/2) とは書かない**。

## 影響

- ACTION 1 のセルから改善機会 16 を外す
- 改善機会 16 の `注意:` に「ACTION 1 の説明には使わない」を書く
