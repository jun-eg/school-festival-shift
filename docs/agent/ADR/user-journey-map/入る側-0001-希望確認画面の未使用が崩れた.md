# ADR 入る側-0001: 「希望確認画面を開いた人はいない (4/4)」が崩れた

- **Status**: 有効
- **Date**: 2026-09-15
- **対象**: docs/journey/入る側.md — ACTION 4・6 / 改善機会 5・6
- **出典**: [`docs/interviews/01-入る側.md`](../../interviews/01-入る側.md)（5 人目 Q4）/ issue #50

## それまでの結論

希望確認画面を開いた人はいない ◎ (4/4)。4 人目は追い質問①で「知らなくて、開いておらず」と答え、
**未使用 4/4** で確定していた（理由は「使わなかった」ではなく「存在を知らなかった」）。

## 何が起きたか

5 人目が Q4 で「**シフト希望確認みた**」と回答。**提出サイトのボタン名と一致する** ◎（記録）。
開いた理由は「あれ何て書いたっけ」の確認 ＝ **控えの確認**である。

同じ人が Q7-1 には「なにそれ」と答えているが、これはこちらの質問文が機能の説明で聞いていたため
（→ `docs/interviews/01-入る側.md` 避ける聞き方）。

## 新しい結論

**開いた人がいる ◎ (1/5)。** 未使用 (4/4) は崩れた。
ただし**画面そのものの良し悪しは取れていない** △（Q7-2 が飛ばされた）。

## 影響

- ACTION 4・6 のセルを書き直す
- 改善機会 5（控えの需要）を「無い」から「満たされていた」に読み替える（→ ADR 入る側-0002）
- 改善機会 6 を「確認画面を開いた人に初めて当たれた ◎ (1/5)」に書き直す
- **(4/4) は「全員」ではなく「当たれた 4 人」でしかなかった** — 証言者節の「証言を一般化するときの注意」へ
