# ADR 入る側-0002: 「控えが無くて困った人はいない」の理由が「需要が無い」から「満たされていた」に読み替わった

- **Status**: 有効
- **Date**: 2026-09-15
- **対象**: docs/journey/入る側.md — ACTION 4 / 改善機会 5
- **出典**: [`docs/interviews/01-入る側.md`](../../interviews/01-入る側.md)（4 人目 追い質問② / 5 人目 Q4）/ issue #42 / #50

## それまでの結論

控えが無くて「困った」と言った人は 0/4 ◎。
4 人目は本体で「確認できなかった気がする」→ 追い質問②で「**特に困らなかった**」と答え、
**希望を絞って出した唯一の人＝控えが最も要りそうな層でも困っていない**ことから、
**控えの需要は「無い」側で確定**していた（改善機会 5 は作る理由にならない）。

## 何が起きたか

5 人目が「あれ何て書いたっけ」になり、**希望確認画面で実際に確認できている** ◎（→ ADR 入る側-0001）。

## 新しい結論

**「困った」は 0/5 のまま崩れていない。** ただし**理由が変わった** ◎ (1/5) —
**需要が無かったのではなく、画面が控えとして機能していた**可能性がある。
**確認しようとする行為は 2/5 で起きている**（4 人目＝できなかった / 5 人目＝できた）。

**「助かった」とも「困った」とも言っていない** △ ので、**需要ありには昇格させない。**

## 影響

- 改善機会 5 の `注意:` を「需要が無い」から「画面が控えとして効いているかどうかを見る」に変える
- ACTION 4 のセルを書き直す
