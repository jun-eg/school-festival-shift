# ADR 入る側-0011: 「提出は深夜である」が崩れた

- **Status**: 有効
- **Date**: 2026-09-17
- **対象**: docs/journey/入る側.md — ACTION 1・3 / 改善機会 1・21・33 / 否定・縮小された / 未検証（△）
- **出典**: [`docs/interviews/01-入る側.md`](../../interviews/01-入る側.md)（記録との突き合わせ）/ issue #74

## それまでの結論

5 人目の 2 件（1 回目 0:44:45 ／ 出し直し 3:11:57）だけを見て、こう書いていた。

> **提出は深夜**（**0:44**）で、**出し直しも深夜**（**3:11**）◎ (2/2) → 「**スキマ時間**」ではなく「**深夜**」である

「スキマ時間」像は [入る側-0009](入る側-0009-自己申告が記録とズレた.md) ですでに一度縮小されており、
その空いた穴に「深夜」を入れた形だった。**根拠は 1 人の中の 2 件である。**

## 何が起きたか

証言者 5 人分の提出タイムスタンプを記録から秒まで引いた ◎（記録。issue #74）。
**初回提出 5 件は、昼 3 件（13:10 / 14:05 / 15:04）・深夜 2 件（0:44 / 0:55）で割れた。**

「深夜 (2/2)」は 5 人目 1 人の中で 2 件を数えたものであり、**(n/m) の m が人ではなくイベントになっていた。**

## 新しい結論

**提出時刻は割れる** ◎（初回提出で昼 3/5・深夜 2/5）。深夜は 5 人目に固有ではなかったが、多数でもなかった。

代わりに、**6 件すべてが 13〜15 時台か 0〜3 時台のどちらかに入る** ◎ (6/6)。
朝（〜12 時）・夕方・夜（16〜24 時）の提出はゼロである。→ 改善機会 33（新設）。

ただし **n=5 であり、帯が 2 つに割れて見えるのは偶然の可能性がある** △。
「この時間帯に告知を出せばよい」まで進めない。

## 影響

- 「否定・縮小された」に「提出は深夜に行われる → **縮小**」を足す
- **改善機会 33 を新設**（時刻が 2 つの帯に寄る）
- 改善機会 1 の `注意:` に、時刻の側からも「スキマ時間」像が戻らなかったことを足す
- ジャーニーマップ ACTION 1・3 のセルに時刻の分布を入れる
- 「未検証（△）」の**「記録から引けば埋まるもの」節を消す**（項目がこれ 1 本だったので節ごと消える）
