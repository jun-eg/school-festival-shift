# ADR 作る側-0002: 「希望確認画面は好評だった」を取り下げた

- **Status**: 有効
- **Date**: 2026-09-13
- **対象**: docs/journey/作る側.md — すでに試したこと / 改善機会 11 / 否定・縮小
- **出典**: [`docs/interviews/02-作る側.md`](../../interviews/02-作る側.md)（取り直し 2026-09-13）/ issue #14

## それまでの結論

自作した 3 つ（確認サイト・希望確認画面・整備スクリプト）のうち、
**唯一評価されたのは希望確認画面（自分の希望の控え）である** ◎。

## 何が起きたか

入る側 2 人目の証言と食い違ったため、証言者本人に確認し直した。
本人の回答: **「好評」は本人の感覚であり、直接言われたわけではない** ○。
本人が「あくまで私の意見です」と述べているため、**インタビューの ◎ ではなく ○** として扱う。

## 新しい結論

**取り下げ ○。** **自作物のうち、入る側に届いたことが確認できているものは無くなった。**
確実に効いたのは**担当者自身の作業を軽くしたもの**（学籍番号キー・整備スクリプト・
JSON のリアルタイム表示）だけ ◎。

のちに入る側 5 人目で**「使われた」までは ◎ になった**（→ ADR 入る側-0001）が、
**「評価された」は依然 ○** — 画面の良し悪しを聞いた問に回答が無い △。

## 影響

- 「すでに試したこと」の希望確認画面の行を書き直す
- 改善機会 11 の根拠から「好評」を落とす
- **HMW に成功事例として持ち込まない**
