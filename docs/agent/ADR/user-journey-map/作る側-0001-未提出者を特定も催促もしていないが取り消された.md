# ADR 作る側-0001: 「未提出者を特定も催促もしていない」が取り消された

- **Status**: 有効
- **Date**: 2026-09-15
- **対象**: docs/journey/作る側.md — ACTION 6 / 改善機会 22・27 / 否定・縮小
- **出典**: [`docs/interviews/02-作る側.md`](../../interviews/02-作る側.md)（思い出し 2026-09-15）/ issue #43

## それまでの結論

2026-09-13 の証言として、こう書いていた ◎。

- **未提出者を特定していない。** そのまま組み、後から申告を受けている
- **催促していない。** LINE グループに 2〜3 回流すだけで、個別 DM もしていない

このため「催促が人間関係のコストを伴い、担当者が心理的に負担している」「未提出者の特定に
毎回の突き合わせコストがかかる」は、どちらも**否定された想定**として扱っていた。

## 何が起きたか

入る側 3 人目の答えを読んだ本人が、**こちらから聞いたのではなく**自分の側の事実を 3 つ思い出した ◎。

- **提出記録（提出者履歴）を確認していた**
- **「この人は学祭に来るだろうに出していない」と気づいた数人に、個別に催促していた**
- **入る側 3 人目もその 1 人で、催促 → 提出の順だった**

**記憶同士の食い違いで、記録では決められない** △（個別 LINE は追えない）。
**後から思い出した方を採る理由**は、**今回の方が具体的**だからである
（何を見たか／どう選んだか／相手を 1 人名指しできる）。2026-09-13 は運用の一般的な説明で、
**例外が引き出されていなかった。**

## 新しい結論

**取り消し ◎。** **特定も催促もしたうえで、なお締切後の提出が残る。**

- 改善機会 22 の中身は「特定していない」ことではなく、**特定・催促してもなお残ること**である
- **催促と提出は順序だけが ◎**（入る側 3 人目）。**催促が提出の原因だったとは誰も言っていない** △
- **突き合わせ先の名簿は無く、「誰が来るはずか」は作る側の頭の中にある** ◎
  → **コストの形が違っただけで、コストはあった**（→ 改善機会 27 が新しく立った）
- **催促そのものが負担だったかは聞けていない** △ — 2026-09-13 の時点では
  「催促していない」と答えていたため、質問が立たなかった

**この立場の ◎ も動く。** 1 人しかいない立場なので、証言が唯一の根拠になっている項目が多い。
→ **入る側から返ってきた答えを、作る側に当て直す往復**が要る。
今回は 1 問の副産物として出てきたのであって、狙って取ったものではない。

## 影響

- ACTION 6 のセルを書き直す
- 改善機会 22 を書き直し、改善機会 27 を新設する
- 「否定・縮小」から 2 行（催促の心理的コスト / 未提出者の突き合わせコスト）を落とす
- 入る側の仮説 2 の前提が崩れる（→ ADR 入る側-0007）
