# ADR 入る側-0010: 「4 人目は割り当て量に不公平を感じている」が追い質問で落ちた

- **Status**: 有効
- **Date**: 2026-09-14
- **対象**: docs/journey/入る側.md — ACTION 9 / 改善機会 14
- **出典**: [`docs/interviews/01-入る側.md`](../../interviews/01-入る側.md)（4 人目 追い質問⑤）/ issue #42

## それまでの結論

「入る側は割り当て量の不公平を感じている」は 2・3 人目で**否定**されていたが、
**4 人目が「少ない」と答えた** ◎ (1/5) ＝ **初の「差がある」側**で、しかも**調理不可の 1 人**である。
調理可否で入れる枠が構造的に違うため、**否定は一度「縮小」に落ちた**。

## 何が起きたか

追い質問⑤で、本人は「**ちょうどよかったです**」◎ と回答した。

## 新しい結論

**不公平感は 0/4 で確定** ◎。**差は認識されているが、不満になっていない。**
**量を均す方向の打ち手は、当たれた 4 人の範囲では必要とされていない。**

効いているのは量ではなく「**シフト表に載らない仕事**」の方である ◎ (1/5)。

のちに 5 人目が「**他の人より長い**」◎ (1/5) ＝ 初の「多い」側を答えたが、
**どう思ったかは取れていない** △ → **5 人目はこの判定に入れず、0/4 のまま据え置く**
（**母数だけ 5 に増やさない**）。

## 影響

- ACTION 9 のセルと改善機会 14 を書き直す
- 「否定・縮小」の「割り当て量の不公平」を **0/4 で否定**に戻す
