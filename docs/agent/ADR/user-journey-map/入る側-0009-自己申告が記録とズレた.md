# ADR 入る側-0009: 1 人目の「締め切り直前」が記録とズレた — 「スキマ時間」の根拠が 1 本弱まった

- **Status**: 有効
- **Date**: 2026-09-14
- **対象**: docs/journey/入る側.md — ACTION 3 / 改善機会 1
- **出典**: 提出記録 / issue #46

## それまでの結論

希望の提出は**スマホのスキマ時間**で行われている ◎。
1 人目の「締め切り直前」＋「スマホ」が、その読みの主な根拠だった。

## 何が起きたか

提出記録のタイムスタンプを突き合わせたところ、
**1 人目の提出は締切 2 日前の 14:05** ◎（記録）だった。
**自己申告「締め切り直前」は体感であって事実ではなかった。**

## 新しい結論

- **記録と自己申告が食い違う場合は記録を採り、自己申告は逐語として併記する**
  （このルールは [`references/evidence.md`](../../../.claude/skills/user-journey-map/references/evidence.md) へ）
- **1 人目に残るのは「スマホ」だけ。** スキマ時間と明言されているのは **2 人目の「電車の中」1/5 だけ**
- **スマホ 3/5 は動かないが、「スキマ時間」まで言うなら根拠は薄い**
- のちに 4 人目（家で 10 分）・5 人目（居酒屋で 10 分・深夜）が加わり、
  **「スキマ時間だから短い」は成り立たない**ことが確定した ◎ (2/5)

## 影響

- ACTION 3 のセルと改善機会 1 を書き直す
- 「否定・縮小」の「提出はスマホのスキマ時間で行われる」を**縮小**にする
