# ADR 作る側-0003: 「全員分が見えるのは評判が悪かった」が「言い過ぎたかもね」に縮小した

- **Status**: 有効
- **Date**: 2026-09-13
- **対象**: docs/journey/作る側.md — 改善機会 12 / 否定・縮小
- **出典**: [`docs/interviews/02-作る側.md`](../../interviews/02-作る側.md)（取り直し 2026-09-13）/ issue #14

## それまでの結論

**全員分の希望が見えるのは評判が悪かった** ◎。

## 何が起きたか

証言者本人に確認し直したところ、

- **複数人から「全員分見れちゃうんだ」と言われた** ◎（本人が直接聞いている）
- ただし **「評判が悪かったは言い過ぎたかもね」** ○

## 新しい結論

**反応が実際に複数人から出ていることは ◎。** ただし**その反応が拒否感なのか単なる驚きなのかは未検証** △
（「評判が悪い」は本人の解釈が入っている ○）。

**「全員分見れちゃうんだ」と言えるのは、確認画面を実際に開いた人である** ◎ →
入る側 ACTION 4 に答えられる**唯一の既知の層**であり、**次に聞く最優先**になった。

のちに入る側 5 人目をその 1 人だと思って聞いたが、**本人ではなかった**（→ ADR 入る側-0003）。

## 影響

- 改善機会 12 を書き直す
- 「否定・縮小」の「評判が悪かった」を **○ のまま・中身は未確定**にする
