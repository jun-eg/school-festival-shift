# ADR 作る側-0004: 「当日のサボり・遅刻は担当者に見えていない」が誤りだった

- **Status**: 有効
- **Date**: 2026-09-13
- **対象**: docs/journey/作る側.md — 改善機会 24・25 / 否定・縮小
- **出典**: [`docs/interviews/02-作る側.md`](../../interviews/02-作る側.md)（取り直し 2026-09-13）/ issue #14

## それまでの結論

入る側 2 人目が、**クリーンパトロールをサボる人がいて、その場に居た別の人が肩代わりしている**
のを目撃していた ◎。作る側はこれを把握していないだろう、と読んでいた。

## 何が起きたか

証言者本人に確認し直したところ、**認識していたが、その場で対応できたのでそこまで覚えていなかった** ○。

## 新しい結論

**誤り ○。** **見えていない穴ではなく、その場で解消されて記録に残らない穴**である。
→ **担当者側の課題としては優先度を下げる。**

**ただし入る側から見た「肩代わり」は不公平として残る** ◎（→ 入る側 改善機会 12）。

## 影響

- 改善機会 24・25 を「認識のうえで当日吸収している」に書き直す
- 「否定・縮小」の「担当者に見えていない」を**誤り**にする
