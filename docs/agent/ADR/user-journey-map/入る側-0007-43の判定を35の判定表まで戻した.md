## それまでの結論

3 人目への追い質問の結果を、一度こう書いていた。

- 3 人目は「b を選ばなかった」ので、**改善機会 16 は b でないと確定した ◎**
- 作る側が催促したあとに提出しているので、**催促が提出の原因である ◎**

## 何が起きたか

#35 の共通ルールと判定表に照らし直した。

- 3 人目は **a/b/c のどれにも答えていない** → 判定表に流せる行が無い。
  **b を選んでいないが、b を否定してもいない** → 「b でないと確定」は成り立たない
- 作る側の証言で ◎ なのは**催促 → 提出の順序だけ**で、
  **催促が提出の原因だったとは誰も言っていない** △。本人は催促に一言も触れていない

## 新しい結論

- 改善機会 16 は **1/5 のまま。(0/2) とは書かない**。3 人目分は **○ のまま確定していない**
