# ADR 入る側-0004: 「締切後に出したのは、告知に気づかなかったからだ」が外れた

- **Status**: 有効
- **Date**: 2026-09-14
- **対象**: docs/journey/入る側.md — ACTION 1 / 改善機会 16
- **出典**: [`docs/interviews/01-入る側.md`](../../interviews/01-入る側.md)（4 人目 追い質問⑥）/ issue #42

## それまでの結論

締切後に出した人がいるのは**告知が届いていなかったから**ではないか、という読み。
ACTION 1（フォームが LINE で届く）の空白は「告知が届かなかった」側にあると見ていた。

## 何が起きたか

4 人目が追い質問⑥で「**a　前日とかに再告知してくれると嬉しいかもです**」と回答 ◎ (1/1)。
**a ＝ 締切は知っていたが後回しになった**である。

## 新しい結論

**外れ ◎ (1/1)。** **告知は届いていて、動かなかった。**
ACTION 1 の空白は「告知が届かなかった」側ではない。

**ただし「なぜ後回しになったのか」は落ちた** △（「もう一言詳しく」に返答なし）ので、
**仮説 2（頼めばどうにかなる）には昇格しない**（→ ADR 入る側-0007）。

代わりに**本人から打ち手が出た** ◎ (1/1):「**前日とかに再告知**」。効くかは未検証 △。

## 影響

- ACTION 1 のセルを書き直す
- 「否定・縮小」に「締切後 ＝ 告知に気づかなかった」を落とす
