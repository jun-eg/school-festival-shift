# E2E が実機で止まるときの要約 — 症状・切り分け・対処

`npm run e2e` が止まる 3 つの事象（A〜C）と、実機で見た 3 つ（D〜F）を、症状から引けるようにまとめた。
A〜C は実機で起こしておらず、人が「確かめずに受け入れる」と決めた（2026-10-25）。文言には、コードから引いたものと、Google 側の返事の推測が混ざる。推測は原本が区別している。D〜F と、Execution API の返事の文言（HTTP 200 の `Error: `・日次上限・存在しない関数・Drive の 403）は、2026-10-25 に実機で見た。

## A. clasp のトークンが 7 日で切れる

- 仕組み: OAuth 同意画面が「テスト」の間、リフレッシュトークンは 7 日で失効する。
- 症状: 出力の最初の API 呼び出しで `access token が取れない: invalid_grant（…）。clasp login をやり直す`。何も書かずに止まる。
- 対処: 人が `clasp login --creds …`（[`e2e/README.md`](../e2e/README.md) の用意するもの 3）をやり直す。承認はブラウザなので Claude にはできない。やり直せば無人に戻るはずだが、失効した状態からは見ていない。

## B. スクリプトと GCP プロジェクトの結び付けが外れる

- 仕組み: `scripts.run` は、呼ぶ側のクライアントとスクリプトが同じ GCP プロジェクトでないと通らない。`.env` の GCP プロジェクトの欄はコードが使っていないので、事前には見つからない。
- 症状: push までは通り、最初の `buildTemplate` が `buildTemplate が失敗した（HTTP <status>）: <本文>` で落ちて、再試行されない。status は 403 か 404 のはずだが推測で、本文も実機で見ていない。
- 対処: A でないことを見て、人がエディタの「プロジェクトの設定」で GCP プロジェクト番号を入れ直す（用意するもの 2）。そのあと Claude が回して通ることを見る。

## C. 呼び出しが 180 秒で切れる

- 仕組み: Node は 180 秒で待つのをやめ、5 秒後に 1 回だけ再試行する。Apps Script 側の実行は止まらず、最大 6 分続くので、1 回目と 2 回目が重なりうる。実機の所要時間は数秒から数十秒で、切れたことは一度も無い。
- 二重に走っても困らない: `buildTemplate` と `e2eGenerate`（どちらも冪等）。困る: `createFormFromPicker`（途中で落ちた後や重なったとき、フォームが 2 つできて孤児が残りうる）。`e2eClearForNextYear` は形は同じだが、2 回目は外したフォームの URL が空で返り、e2e の検査が落ちる。フォームは控えから次の回の頭で捨てられる。
- 症状: 最後の例外は Node の中断（推測: `The operation was aborted due to timeout`）か `<関数名> が失敗した（HTTP <status>）: <本文>`。スクリプトの例外は、実機で見たとおり HTTP 200 で、本文に `Error: ` が付く（再試行しない）。切り分けはエディタの「実行数」で同じ関数が 2 本あるかを見る。
- 対処: 冪等なものは回し直す。フォームの孤児は次の回の頭で拾い、拾えないものは人がドライブで探してゴミ箱へ移す。

## D. 初回だけ `reading from storage … NOT_FOUND`（実機で見た）

push 直後の最初の呼び出しだけ返り、5 秒後の 1 回の再試行で通る。止まらないので何もしない。2 回目も出るなら push 先か B を疑う。

## E. 続けて回すと頭で落ちた（直した）

- 前の回の「回答」の紐付けと一時シートが残り、頭の「空に戻す」で落ちた。#349 で、流れの最後で紐付けを外し、頭で紐付いた全シートの紐付けと一時シートの残りを拾うようにした。
- 拾えないとき: 人が「回答」タブの ▼ →「フォームのリンクを解除」を押し、余分な「フォームの回答 N」を消す。

## F. Execution API と Drive の止まり方（実機で見た）

- 日次上限: `今日の scripts.run が上限（100 回）に達した…` で呼ぶ前に止まる。存在しない関数は `Script function not found` で 1 回で止まる。
- 控え `.e2e/quota.json` は worktree ごと・日付は UTC。worktree をまたぐと「1 日 100 回」は効かない（2026-10-24 は 2 つで 160 回超）。
- ゴミ箱へ移す: フォームでないファイルは何もせず止まる。書き込みは 403（`appNotAuthorizedToFile`）。403 の案内文の経路は未確認。

詳しくは [原本](agent/e2e-症状と対処.md)。起こしていないのは、7 日で切れること・再ログインで戻ること・B の status と本文・180 秒で切れたときの重なり・Drive の 403 の案内文の経路。
