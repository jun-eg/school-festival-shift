### この証言を一般化するときの注意

**証言者は技術力が高い側の外れ値**である ◎。担当は**毎年 1 人が持ち回りで、幹部のこともメンバーのこともある** ◎ ため、

### 立場を 1 人に絞った理由

「シフトを作る人」と「シフトに入る人」で体験が分かれるが、**このペルソナは両方を兼ねている** ◎。
マップの視点は **「作る人」としての体験**に固定する。

> **当初の想定は否定された。** 「作る側なので自分の希望を後回しにする」という体験は**無かった** ◎。
> 入る時間が多かったのは事実だが、理由は「幹部でどうせ大学に居るから」であり、シフト作成担当だからではない ◎。
> 担当者の負担は**割り当ての不利ではなく、無報酬の作業量そのもの**に出ている ◎。

## 証言された「理想の状態」

インタビューで**そのまま語られた**理想のフロー ◎。HMW と Design Doc の User Story の一次情報になる。

```
LINE にアンケート URL を貼る
  ↓
「シフト作成」ボタンを押す
  ↓
仮完成
  ↓
ちまちま手で少し修正（5〜15 分）
  ↓
完成
  ↓
LINE に流す
  ↓
修正依頼が来る
  ↓
手で修正（5〜15 分）
  ↓
LINE のノートを差し替える
```

読み取れること:

- **全自動は求められていない。** 「仮完成 → 手で微修正」が前提に入っている ◎
- 許容できる手作業は **5〜15 分**。現状の **3〜6 時間**との差が、解くべき距離 ◎
- 修正ループ（流す → 依頼が来る → 直す）も**同じ 5〜15 分**で回ることが期待されている ◎
- 出入口は **LINE** のまま ◎。置き換え対象は**割り当ての中身だけ**

## 確定した改善機会リスト

HMW（次工程）の入力。**解決策ではなく「機会」**として書いている。

### 確定（◎：インタビューで裏が取れた）

**最優先 — 割り当て**

1. 割り当てが全工程で唯一かつ最大のボトルネックになっている（3〜6 時間／3 日がかり／やり直し 20 回規模）
2. 「検便 × 学年（3・4 年）× 時間が合う」の 3 条件で調理系の候補が枯れ、**公平性を犠牲にしてでも同じ人を入れている**
3. 準備・片付けの割り当てルール（午前に仕事→準備／午後に仕事→片付け／両方ある人は片方）が複雑で、**片付けは配慮そのものを諦めている**
4. 「公平」の基準（準備の回数・シフト回数・合計時間）が担当者の頭の中にあり、確かめる手段が目視しかない
5. 粗い単位で集めた希望を 30 分枠に割り直す変換が、担当者の頭の中でしか行われていない
6. 集めたのに使われない希望（「一緒に組めたら嬉しい友達」）があり、入力側のコストが無駄になっている
7. 修正のたびに、初回と同じ制約チェック（検便・学年・時間）を手でやり直している

**引き継ぎ**

8. 担当が毎年入れ替わるのに、渡るのは**前年のシフト表 1 枚と LINE の一文**だけ
9. 作り込んだフォーム・バリデーション・スクリプトが翌年に一切残らない（「整ったデータの集まるフォームは引き継げない」）
10. 各工程の重さが、**その年の担当者の技術力だけで決まってしまう**
11. 必要人数の根拠が「去年と同じ」しかなく、妥当性の検証も翌年への引き渡しもできない
12. 委員会のルール（検便・学年・クリーンパトロール）が文書化されず人伝いに渡っている

**順序・タイミング**

13. クリーンパトロールの枠が**フォーム作成後**に確定するため、枠設計が後から崩れる
14. 日ごと・年度ごとに営業時刻が変わるため、前年の成果物を再利用できない
15. 未提出者を特定しないまま割り当てが始まり、後から申告（締切後提出 5 人・流した後の指摘 1〜2 人）が来て組み直しになる

**担当者の立場**

16. 担当者が無報酬で、模擬店の他の役割（調理・準備・片付け）と兼任している

### 否定・縮小された（当初の想定と実態が違った）

HMW で**これらを解きにいかない**ために残す。

| 当初の想定 | 実態 ◎ |
| --- | --- |
| 催促が人間関係のコストを伴い、担当者が心理的に負担している | **催促していない。** LINE グループに 2〜3 回流すだけ。個別 DM もしていない |
| 未提出者の特定に毎回の突き合わせコストがかかる | **未提出者を特定していない。** そのまま組み、後から申告を受けている |
| 回答データの整理に人力の変換工程が挟まる | 証言者の年は**スクリプトで解決済み**。ただし例年は手作業の可能性 ○（未検証） |
| 最新版がどれか定まらず、古い表が参照され続ける | **起きていない。** LINE ノートの画像を差し替えるため古い版は残らない |
| 当日の欠員が担当者の即興対応で吸収され、大きな負担になっている | **困っていない。** 大学に居るメンバーから即座に出せる。優先度は低い |
| 埋まらないコマが出て、その存在に後から気づく | **埋まらなかったコマは無い。** 代わりに「公平性を欠いてでも埋めた」が起きている |
| 担当者自身の希望が後回しにされ、割り当てで不利になっている | **無い。** 入る時間が多いのは幹部だからであって、担当だからではない |

### 未検証（△：まだ誰にも聞けていない）
