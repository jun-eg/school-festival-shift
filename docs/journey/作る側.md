# ジャーニーマップの要約 — シフトを作る側

サークルの模擬店でシフト作成を任された人の体験を、担当になってから当日の穴を埋めるまでの 12 の行動で追ったもの。
前回の担当者 1 人への聞き取りと、その人が編集していた確定シフトの記録から書いてある。
証言者は技術力が高い側の外れ値で、例年の担当者が同じことをできるとは限らない。

## ペルソナ

佐藤 みなみ（仮名）。大学 3 年。担当は毎年入れ替わり、押し付けか幹部の持ち回りで決まる。
引き継がれるのは前年のシフト表 1 枚と LINE の短い説明だけ。自分もシフトに入り、調理や準備・片付けも兼任する。
無報酬で、学祭運営委員会の外部ルール（検便、調理責任者は 3・4 年生、クリーンパトロールの指定枠）に縛られる。

## 分かったこと

- 全工程で唯一かつ最大のボトルネックは割り当てである。3 日に分けて 3〜6 時間かけ、一箇所直すと別が崩れるやり直しを 20 回ほど繰り返す
- 重さの中身は、検便・学年・時間の 3 条件で候補が枯れる探索と、頭の中にしかない準備・片付けのルールと公平の基準である
- 理想は全自動ではない。仮完成が出て手で 5〜15 分直す形で、出入口は LINE のままでよい
- 自作した正規表現バリデーション、学籍番号キー、整備スクリプト、提出履歴サイトは効いたが、どれも翌年に渡らない。見える化（JSON とリアルタイム表示）だけでは時間は縮まなかった
- 工程の重さは、その年の担当者の技術力で決まる。前々年度は手でエクセルに転記していた
- 未提出者は提出履歴で特定し、数人に個別に催促している。それでも締切後の提出が 6 人分出る
- 割り当て時に名簿は使っていない。調理可否はフォームの申告を提出履歴サイトで見ている
- 事後の申し出は LINE に入り、記録に残らない。件数は記録からは 0 人で、復元する道が無い
- 当日のサボりや遅刻は認識したうえでその場で吸収しており、担当者側の困りごとではない
- 出し直しは 11 行あるが、自動で畳んでいるので作る側の手間としては見えていない

## 開いていること

- 技術力の低い年の担当者に当たれていない。手作業でのデータ整理やフォーム作成にかかる時間が分からない
- 他年度・他サークルの担当者に当たれていない。この学祭で共通の課題か、このサークル固有かが分からない
- 催促が負担だったか、催促しても出さなかった人がいたか、必要人数（調理責任者 1・調理 2・会計 1・呼び込み 2・列整理 2）が妥当だったかは、聞けていない
