# ADR dev-env-0001 の要約

テンプレートに貼る物が、`src/` の 20 ファイルから、ビルドが出す `dist/` の 4 つ（`main.gs`・HTML 2 枚・`appsscript.json`）に変わった。「clasp を本筋にしない」の理由のうち、インストール 0・貼るのは 1 回・ファイル名が 1 対 1 の 3 つは成り立たなくなった。
今は、タグを打ってから `npm run build` で作り、貼る。`dist/` は git に入れず、タグの無い `dist/` は貼らない。
貼った版（タグ、無ければ短い SHA）は、メニュー「シフト」末尾の「バージョン」で読める。担当者の操作は増えない。
clasp は、テンプレートへの差し替え（手貼りが原本）と、検証用スプレッドシートへの `clasp push`・`clasp run`（開発側の本線）に分けて書く。`.claspignore` は消した。
