# ADR design-doc-0007 の要約

友達欄を「フォームに残すだけで、誰も読まない」としていたのが崩れた。担当者が余裕のあるときに手で寄せるための列として、
割り当てのマス目に氏名と並べて出す。生成は読まず、書式の縛りは外して自由記述にした。MVP の外である。
