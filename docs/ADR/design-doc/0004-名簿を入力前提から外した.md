# ADR design-doc-0004 の要約

調理担当者名簿を「そのまま入力に取る」としていたのが崩れた。割り当て時に名簿は使われておらず、調理可否の出どころはフォームの申告である。
名簿はフォームに貼る画像としてだけ複製し、入力の型は 7 項目から 6 項目になった。
