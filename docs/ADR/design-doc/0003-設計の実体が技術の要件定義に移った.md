# ADR design-doc-0003 の要約

設計の実体が Design Doc の 6・7 に溜まっていたので技術の要件定義に移し、「変換規則は技術側に送らない」の明記を取り消した。
器ができ、規則を発明しないという決まりが器の側にあるためである。Design Doc には判断と裏付けだけが残る。
