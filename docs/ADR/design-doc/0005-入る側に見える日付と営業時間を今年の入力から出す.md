# ADR design-doc-0005 の要約

「フォーム定義は転記で、変える判断をしない」に例外が立った。入る側に見える設問の日付と説明文の営業時間は、今年の条件入力から出す。
前回の値を貼ったフォームのほうが「入る側がその年の正しい日付を見る」という Before を壊す。学祭は例年 4 日で固定なので、ラベル 4 つは定義側が持つ。
