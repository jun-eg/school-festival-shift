# ADR design-doc-0006 の要約

出し直しのどの行を採るかが空欄のまま、下流を止めていた。タイムスタンプが最も新しい 1 行を採る。出し直しは希望そのものの修正だからである。
締切では切らない。キーが同じ 2 行は選ばずに名指しで返す。
