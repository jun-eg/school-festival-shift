# ADR 作る側-0003 の要約

「全員分が見えるのは評判が悪かった」が「言い過ぎたかも」に縮小した。
複数人から「全員分見れちゃうんだ」と言われたことは確かだが、それが拒否感なのか驚きなのかは分からない。
