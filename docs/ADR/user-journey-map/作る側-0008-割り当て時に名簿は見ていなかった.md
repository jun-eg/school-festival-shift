# ADR 作る側-0008 の要約

「調理系の 3 条件を名簿と照合する」が崩れた。割り当て時に見ていたのは自作の提出履歴サイトにある申告の列で、名簿は使っていない。
名簿の役割は、フォームに画像として貼られて本人が申告するために見ることだけになった。自作サイトの呼び名は「シフト希望提出履歴サイト」に揃えた。
