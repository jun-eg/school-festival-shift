# ADR 入る側-0012: 「友達欄の指定が守られていない ◎ (4/5)」が崩れた — インタビューで見えていた属性・個人名は、記録に 1 件も無かった

- **Status**: 有効
- **Date**: 2026-09-17
- **対象**: docs/journey/入る側.md — 改善機会 2・3・24・25 / ACTION 3 / 「5 人を並べて言えること」/ 否定・縮小 / 未検証
- **出典**: 希望収集フォームの設定と収集データ（保持者への聞き取りで形と件数のみ起こした） / issue #83

## それまでの結論

- 改善機会 3「フォームが友達欄に指定した学籍番号が、**守られていない** ◎ (4/5)」
  根拠は「指定どおりと分かるのは 1 人だけで、**残りは空欄・属性・個人名で書いている**」だった
- 改善機会 24「書かれた友達欄のうち、**一意に辿れる形は一部である** ◎ (3/5)」
  根拠は「学籍番号 1・個人名 1・役職 1 は辿れるが、**「同期の女」は誰か分からない**」だった
- 「5 人を並べて言えること」の軸は「書いた 4/5・空欄 1/5（うち個人名 1・属性 2）」
- ACTION 3「正規表現バリデーションで弾かれた人はいない ◎ (5/5)」

**どちらの根拠も、インタビューの答えの形をそのまま「フォームに書かれた値」として読んでいた。**

## 何が起きたか

**記録を引いた。**

- 友達欄は**任意項目** ◎ で、正規表現 `^(?:[A-Za-z0-9]{10})(?:,[A-Za-z0-9]{10})*$` が掛かっていた ◎。
  **10 桁の英数字しか通さず、カンマ区切りで複数人を書ける。** 説明欄に記入例が出ている ◎
- 収集データの友達欄は **学籍番号 24 件・空欄 15 件**で、**属性・個人名は 0 件** ◎。
  **提出記録は全 50 行だが、うち 11 行は出し直しで実人数は 39 人** ◎（→ [入る側-0013](入る側-0013-出し直しは1件ではなく11行あった.md)）
- 証言者 5 人の突き合わせ — **4 人目**（「サー長の先輩みたいにしました」）**と 5 人目は記録が学籍番号**、
  **1・2・3 人目は記録が空欄**。1 人目は Q3 でも「何も書いていない」◎ なので元から整合する

**つまり 2・3 人目の「同期の女」「友達の名前」は、フォームに入力された値ではなかった。**
改善機会 3 と 24 は、どちらも**記録に存在しない値**を根拠にしていた。

## 新しい結論

- 改善機会 3 →「友達欄は、**提出の 4 割弱が空欄のまま出されている** ◎（記録 15/39）」。
  **書かれた分は全件が指定どおり**で、**落ちているのは書式ではなく入力そのもの**である
- 改善機会 24 →「友達欄が一意に辿れるかは、**書き方ではなく相手が希望を出しているかで決まる** ◎（記録 24/24 が学籍番号）」。
  **一意性の限界は形から照合先に移った** △ — **相手が希望を出していなければ提出記録に照合先が無い**。
  確認サイトは全員が閲覧できる ◎ ので、**未提出者の学籍番号も書ける**
- 軸 →「**記録では記入 2/5・空欄 3/5** ◎（記録）」
- ACTION 3 の「弾かれた人はいない ◎ (5/5)」は**自己申告として据え置く**。
  **記録と食い違う人が 2 人いる** ◎ ことを併記した（→ ADR 入る側-0009 と同じ扱い）
- 改善機会 2 は判定を維持し、**期待が乗っているのは提出の 6 割** ◎（記入 24/39）という規模を足した
- 改善機会 25 は **(1/5) のまま据え置く**。記録上の記入者はもう 1 人いる ◎ が、
  **その人が手間を口にしたかは聞いていない** △

**決めきらずに残したもの。**

- **空欄 15 件のうち、「弾かれて諦めた」と「最初から書く気がなかった」は区別できない** △。
  記録に残るのは提出された値だけで、弾かれた事実は残らない。**1 人目は後者と分かっている** ◎
- **友達欄の学籍番号に、提出記録の中へ照合先が無いものが何件あるか** △
- **「約 11 人」はざっと見た数で、厳密な人数は詰めていない** △（→ [入る側-0013](入る側-0013-出し直しは1件ではなく11行あった.md)）

## 影響

- 改善機会 3・24 を書き直す。改善機会 2・25 の注意に記録の数字と △ を足す
- ACTION 3 の TASK LIST に記入 24/39・空欄 15/39 を入れ、IMPROVEMENT の 1 本目を自己申告と明示する
- 「5 人を並べて言えること」の友達欄の軸を記録ベースに差し替える
- ペルソナの制約「フォームは友達欄に学籍番号を要求する ◎」に、正規表現の形と任意項目であることを足す
- 「否定・縮小」に **「指定した学籍番号は守られていない → 否定 ◎」** を足し、
  既存の「出す側も書いていない → 否定」の根拠を (4/5) から記録 (24/39) に差し替える
- 「未検証（△）」の 2 本（友達欄が他人に見えると知っていたか／書いた内容が通ったと思っているか）を
  記録に合わせて直し、**空欄の内訳**と**照合先の無い学籍番号**の 2 本を足す
- [`docs/interviews/01-入る側.md`](../../interviews/01-入る側.md) の Q3 の △
  「2〜4 人目の答えも同じ目で読み直す必要がある」を、記録で閉じた形に更新する
- 作る側の裏側は [作る側-0006](作る側-0006-友達欄の指定が守られていないが崩れた.md)
- **`docs/design-doc.md` は変更しない。** §6 が友達欄をスコープ外に置く理由は
  「捨てている理由が余裕がない ◎」と「一意にすると入る側が止まる ◎（入る側 25）」であって、
  **「守られていない」を根拠にしていない**。どちらも今回の記録で動いていない
