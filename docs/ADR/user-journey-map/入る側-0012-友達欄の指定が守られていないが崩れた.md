# ADR 入る側-0012 の要約

「友達欄の指定が守られていない」が崩れた。記録では、書かれた 24 件は全件が学籍番号で、空欄が 15 件だった。
インタビューで聞こえた属性や個人名は、フォームに入力された値ではなかった。落ちているのは書式ではなく入力そのもので、
一意に辿れるかは書き方ではなく、相手が希望を出しているかで決まる。
