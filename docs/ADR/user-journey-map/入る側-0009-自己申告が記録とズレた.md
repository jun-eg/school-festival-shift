# ADR 入る側-0009 の要約

1 人目の「締め切り直前に出した」が記録と食い違った。実際は締切の 2 日前の昼だった。
記録と自己申告が食い違うときは記録を採り、自己申告は逐語として併記する。「スキマ時間で出す」という像の根拠は薄くなった。
