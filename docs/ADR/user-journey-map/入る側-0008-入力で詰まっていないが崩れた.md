# ADR 入る側-0008 の要約

「入る側はフォームの入力で詰まっていない」が崩れた。止めたのは正規表現ではなく、友達の学籍番号という、項目が要求する材料だった。
材料が無くて止まった人は 2 人いて、入力体験を軽くしてもこの 2 人には当たらない。
