# ADR 入る側-0008: 「入る側はフォームの入力で詰まっていない (4/4)」が崩れた

- **Status**: 有効
- **Date**: 2026-09-15
- **対象**: docs/journey/入る側.md — ACTION 3 / 改善機会 1・3
- **出典**: [`docs/interviews/01-入る側.md`](../../interviews/01-入る側.md)（5 人目 Q1）/ issue #50

## それまでの結論

正規表現バリデーションを入れた年だが、**弾かれたという答えは 4 人とも出ていない** ◎ (4/4)。
「バリデーションを厳しくした年は入る側が入力で詰まっていた」という想定は否定されていた。

## 何が起きたか

5 人目が「**一緒に組みたい友達の学籍番号確認が時間かかった**」と回答 ◎ (1/5) —
**フォーム側で止まっている**。

## 新しい結論

**崩れた。ただし崩れ方が想定と違う** ◎ (1/5) —
**止めたのは正規表現ではなく、項目が要求した材料**（他人の学籍番号）である。

**4 人目の「時間の判断で 10 分」と同型**で、**材料不足で止まったのは 2/5** ◎
→ **入力体験を軽くしても、この 2 人の詰まりには当たらない。**

**一意に辿れる友達欄を要求すると、そのコストは入る側に出る**（改善機会 3）。

## 影響

- ACTION 3 のセルを書き直す
- 「否定・縮小」の「バリデーションで詰まっていた」を書き直す
- 改善機会 3 に「一意にするコストは入る側に出る」を足す
