# ADR 作る側-0004 の要約

「当日のサボりや遅刻は担当者に見えていない」が誤りだった。認識したうえでその場で対応していたので、記録に残らなかっただけである。
担当者側の課題としては優先度を下げる。入る側から見た肩代わりの不公平は残る。
