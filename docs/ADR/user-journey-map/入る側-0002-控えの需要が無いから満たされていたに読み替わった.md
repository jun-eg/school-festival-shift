# ADR 入る側-0002 の要約

控えが無くて困った人がいない理由が、「需要が無い」から「画面が控えとして効いていた」に読み替わった。
確認しようとした人は 5 人中 2 人いる。助かったとも困ったとも言っていないので、需要ありには昇格させていない。
