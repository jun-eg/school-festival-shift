# ADR 作る側-0001 の要約

「未提出者を特定も催促もしていない」が取り消された。提出履歴を見て気づいた数人に、個別に催促していた。
特定も催促もしたうえで締切後の提出が残る。突き合わせる名簿は無く、「誰が来るはずか」は担当者の頭の中にある。
