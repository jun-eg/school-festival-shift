# ADR 入る側-0011 の要約

「提出は深夜である」が崩れた。5 人の初回提出は昼 3 件と深夜 2 件に割れた。
6 件すべてが 13〜15 時台か 0〜3 時台に入るが、人数が少ないので告知の時間帯の根拠にはしない。
