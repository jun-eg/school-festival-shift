# ADR 作る側-0005: 申し出の件数が「記憶では 1〜2 人」から「記録からは 0 人」で確定した

- **Status**: 有効
- **Date**: 2026-09-15
- **対象**: docs/journey/作る側.md — ACTION 11 / 改善機会 26
- **出典**: [`docs/interviews/01-入る側.md`](../../interviews/01-入る側.md)（5 人目 Q8・Q13）/ 提出記録 / issue #50 / #48

## それまでの結論

事後の申し出は **記憶では 1〜2 人** ◎、**記録で名指しできたのは 1 人** ◎（記録）。
その 1 人は A 経路（フォームから出し直す）を通ったので提出記録に現れていた。
#45 は、その人が出し直す前に「今から出してもいい？」と可否を聞いてきた、と ◎ で書いていた。

## 何が起きたか

本人（入る側 5 人目）に聞いた結果、

- 「**希望と違うコマは入ってない**」◎ → **申し出ではなかった**
- 「**聞かずに出して事後報告した**」◎ → **可否を聞いてきたのは記憶** ○ **であって記録ではない**
- 記録の順序: **出し直し 10/27 3:11:57 < シフト表の配布 10/27 深夜** ◎（記録）
  → **「シフト表を見ての申し出」ではなく「希望そのものの修正」**

## 新しい結論

**申し出の件数は、記録からは 0 人で確定した** ◎。**記憶 ○ だけが残る。**

**「記録に残った 1 人＝申し出た 1 人」ですらなかった。**
A 経路に見えたものは実は希望の修正で、**B 経路（LINE 直申告）は何も残さない** →
**申し出が実際に何件あったのかを、記録から復元する道は無い。**

さらに **C 経路（入る側同士の相対交代）** の話が 1 件ある ○（又聞き）。
**B が「処理したが残らない」のに対し、C は「処理すらしていない」。**

→ **HMW では「ちゃんと記録する」を解きにいかない。**
**担当者の記録癖の問題ではなく、経路の置き場所の問題である** ◎。

## 影響

- ACTION 11 の経路 A の記述を直す（可否を聞く → 記憶 ○）
- 改善機会 26 を書き直す
- 入る側 ACTION 7 は空白のまま閉じる（→ ADR 入る側-0006）
