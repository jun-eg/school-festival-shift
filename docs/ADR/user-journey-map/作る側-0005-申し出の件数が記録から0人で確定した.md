# ADR 作る側-0005 の要約

事後の申し出の件数が「記憶では 1〜2 人」から「記録からは 0 人」で確定した。記録に残っていた 1 人は希望の修正で、
LINE での直申告は何も残さない。何件あったかを記録から復元する道は無く、HMW では「ちゃんと記録する」を解きにいかない。
