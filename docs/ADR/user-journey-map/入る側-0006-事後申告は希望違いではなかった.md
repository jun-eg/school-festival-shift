# ADR 入る側-0006 の要約

記録に残る出し直しは「希望と違うコマが入った」という申し出だ、という読みが外れた。
配布より前に出された、希望そのものの修正だった。シフト表を見てから申し出た経験のある人は 5 人の中におらず、その体験は空白のまま閉じた。
