# ADR 入る側-0006: 「記録に残っている出し直しは『希望と違うコマが入った』という申し出である」が外れた

- **Status**: 有効
- **Date**: 2026-09-15
- **対象**: docs/journey/入る側.md — ACTION 7 / 改善機会 10・18
- **出典**: [`docs/interviews/01-入る側.md`](../../interviews/01-入る側.md)（5 人目 Q8・Q13）/ 提出記録 / issue #50 / #48 / #45

## それまでの結論

ACTION 7（希望と違ったら申し出る）は実体験ゼロ △ のままだったが、
**記録で名指しできる唯一の「出し直した人」＝ 5 人目**が唯一の経路として残っていた。
#45 は「その人は出し直す前に『今から出してもいい？』と可否を聞いてきた」を ◎ として書いていた。

## 何が起きたか

- 5 人目は Q8 で「**希望と違うコマは入ってない**」◎
- Q13 で「**聞かずに出して事後報告した**」◎ → **可否を聞いてきたのは作る側の記憶** ○ **であって記録ではない**
- 記録の順序が合わない ◎（記録）: 締切 10/25 → 1 回目 10/25 0:44:45 → **出し直し 10/27 3:11:57** →
  **シフト表の配布 10/27 深夜**。**修正の方が先**である

## 新しい結論

**外れ ◎ (1/1)。** 記録に残る出し直しは、**「申し出」ではなく「希望そのものの修正」**だった。
**ACTION 7 の実体験ゼロ (5/5) は、推測ではなく記録で確定した** ◎。

LINE 直申告の分は記録が残らず追えない △ ので、**当てられる相手はもういない** →
**ACTION 7 は空白のまま閉じる**。

**何をどう直したのかは取れていない** △（Q12 が丸ごと落ちた。追い質問はしない）。

## 影響

- ACTION 7 のセルを書き直す
- 改善機会 10 を「実体験ゼロが記録で確定」に書き直す
- #45 が ◎ として書いていた「可否を聞いてきた」を ○ に直す
