# ADR 作る側-0006 の要約

「友達欄の指定が守られていない」が崩れた。書かれた分は全件が指定どおりで、提出の 4 割弱が空欄のまま出されている。
弾かれて空にしたのか、最初から書かなかったのかは記録では区別できない。
