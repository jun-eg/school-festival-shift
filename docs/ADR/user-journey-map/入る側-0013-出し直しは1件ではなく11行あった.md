# ADR 入る側-0013 の要約

「記録で名指しできる唯一の出し直した人」が、「唯一の、締切後に出し直した人」に縮小した。
出し直しは記録に 11 行あり、ほぼ締切内で起きている。人数は行ではなく人で数え、39 人とする。
