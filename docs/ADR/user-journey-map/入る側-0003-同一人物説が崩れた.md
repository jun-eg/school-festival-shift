# ADR 入る側-0003 の要約

5 人目が「全員分見れちゃうんだ」と言った本人だという読みが崩れた。誰が言ったかの記録は無く、特定する道はもう無い。
同じ画面を開いた別の 1 人の反応（友達の番号が見えて気まずい）は取れたが、友達欄への反応かという仮説は未判定のまま。
