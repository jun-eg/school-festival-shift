# ADR 入る側-0003: 「5 人目＝『全員分見れちゃうんだ』と言った本人」説が崩れた

- **Status**: 有効
- **Date**: 2026-09-15
- **対象**: docs/journey/入る側.md — 証言者 / 仮説の判定（仮説 1）/ ACTION 4 / 改善機会 6
- **出典**: [`docs/interviews/01-入る側.md`](../../interviews/01-入る側.md)（5 人目 Q11）/ issue #50 / #44

## それまでの結論

作る側本人の記憶 ○ として、**#44 の相手（「全員分見れちゃうんだ」と言った人）と
#45 の相手（記録で名指しできる出し直した人）は同一人物**とされていた。
5 人目に当たれば、あの発言の中身が取れるはずだった。

## 何が起きたか

5 人目が Q11 で「**言った本人ではない**」と回答 ◎。
一方で「**そういう意見は聞いたことがある**」○（又聞き）／「**自分もそう思った**」◎ と答え、
**黙って同じ画面を開いた別の 1 人の反応**としては取れた —
「**誰と組みたいか番号が見えた**」「**困らないけど、気まずい**」◎ (1/1)。
こちらから「友達欄」という言葉は出していないので誘導ではない。

## 新しい結論

**同一人物説 ○ は崩れた。** 一次記録が無い項目で記憶 ○ を当てにいって外れた形である。
**誰が言ったかを残した記録は無い** ◎ ので、**言った本人を特定する道はもう無い** △
（#44 の「やること 1：特定する」は**特定不能**として閉じた）。

**仮説 1（友達欄への反応か）は ○ のまま。** 間接的な支持が 2 つ付いただけである。

## 影響

- 証言者節の「当たれていない層」に「言いに来た人」を残す
- 「仮説の判定」節の仮説 1 を「判定不能（○ のまま）」に据え置く
- 改善機会 6 の `注意:` に「この (1/1) は言った本人の意図ではない」を書く
