# ADR 入る側-0005 の要約

4 人目が締切に遅れたのは他サークルの予定が決まっていなかったからだ、という読みが外れた。
時間に迷ったことと締切に遅れたことは別の話で、改善機会 16 は提出の遅れの説明には使わない。
