# ADR tech-requirements-0005 の要約

前回の確定シフトの転記の実体が、要件定義書から data/ の隣に移った。記録を引き直すたびに要件定義書が 100 行単位で伸びていたためである。
要件定義書に残るのは、何を転記元にしたかと変えないという判断だけで、記録を見れば確かめられる文は data/前回の確定シフト.md が持つ。
