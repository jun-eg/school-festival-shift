# ADR tech-requirements-0013 の要約

「前の周の出力を別に持たない」が崩れた。実機で続けて 2 セルを書き換えると編集イベントが 1 回しか走らず、2 手目の手直しが黙って消えた。
生成と数え直しのたびにマス目の控えをシートの見えない所に置き、控えと違うのに印の無いセルに印を付けてから動く。同じ値に書き直した手だけは拾えない。
