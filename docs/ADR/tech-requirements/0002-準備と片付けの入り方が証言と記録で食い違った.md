# ADR tech-requirements-0002 の要約

取り消し（0003 が上書き）。準備・片付けの入れ方が担当者の証言と前回の確定シフトで食い違ったので、規則 3 の「午前だけなら準備」などをいったん規則から降ろした。
取り消されたのは「規則から降ろす」という判断だけで、食い違いが実在したという観測は生きている。担当者に確かめた結果は 0003 にある。
