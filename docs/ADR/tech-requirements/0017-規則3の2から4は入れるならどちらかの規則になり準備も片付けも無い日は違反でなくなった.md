# ADR tech-requirements-0017 の要約

規則 3 の「午前だけなら準備に入れる」などが、義務から「入れるなら、どちらに入れるか」という向きの規則に変わった。準備も片付けも無い日は違反でなくなった。
担当者の手順が「入れた後で削る」で、記録にもそういう人がいて、人数の不足は未充足が名指しするためである。
これで帯を希望していない人も店に置けるようになり、「1 枠も置かれない人は規則 3 で決まる」とした 0011 は上書きされた（まとまりと散らしの決めは有効のまま）。
