# ADR tech-requirements-0008 の要約

「日と時間帯を空けた需要の行は全枠に効く」が、営業していない帯にまで店の需要を立てていた。準備日の朝 8 時に呼び込みが要ることになっていた。
時間帯を空けた行はその日の調理帯に効くことにし、委員会の指定枠を判定入力に入れた。空欄の読みと準備・片付けの扱いは 0009 でさらに動いた。
