# ADR tech-requirements-0009 の要約

「準備・片付けは需要に立てない」が、準備日と片付け日を丸ごと空にした。規則 3 は店の役割に就いた人に準備・片付けを乗せる規則で、
店の役割が無い日には当たらない。準備・片付けも需要に立て、空欄の時間帯はその役割の帯に効くことにし、埋める段に 4 段目を足した。
人数は記録から導かず、担当者が入力する。
