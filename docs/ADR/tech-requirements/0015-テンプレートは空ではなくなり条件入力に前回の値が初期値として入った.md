# ADR tech-requirements-0015: 「テンプレートは空である（前年の値を既定にしない）」が崩れ、条件入力に前回の値が初期値として入った

- **Status**: 有効
- **Date**: 2026-09-23
- **対象**: `docs/tech-requirements.md` — **5-1 の #1 の値の出どころ** ／ **6 の #1 の却下側の最後の一文**
  ／ `docs/design-doc.md` — **6 の「すでにあるもの」の表（日ごとの営業 4 時刻）** ／ 締切の段落
  ／ `src/sheet-layout.js`（条件入力 6 区画の `initialRows`）／ `src/build-template.js`（`putInitialRows`）／ `src/README.md`
- **出典**: [issue #240](https://github.com/jun-eg/school-festival-shift/issues/240)

## それまでの結論

**テンプレートの入力欄には、初期値を 1 つも置いていなかった。**
**空であること自体が「前年の値を既定にしない ◎」を満たす**、と読んでいた。

> 5-1 の #1（枠）の値の出どころ: **毎回入力する。**前年の値を既定にしない ◎（作る側 21）。

> 6 の #1 の却下側: **テンプレートが空であること自体が、上流の「前年の値を既定にしない ◎」**（→ 5-1 の #1）**を満たしている**

> Design Doc 6: | **日ごとの営業 4 時刻** | … | 毎回入力する。**前年の値を既定にしない**（候補 F の却下理由と同じ） |

**理由は候補 F の却下と同じだった** — **4 時刻は日ごと・年度ごとに変わる ◎**（作る側 21）ので、前年の枠は今年に乗らない。

## 何が起きたか

**issue #240 で、条件入力の 6 区画に初期値を置くことになった。**値は issue に貼られた表で、**前回（2025 年）の条件**である
（日ごとの営業時刻 4 日・役割と必要人数 11 行・調理責任者の学年 3 と 4・委員会の指定枠 2 行・境目 12:00・連続して入る最小の長さ 1:00）。

**issue に書かれているのは表だけで、理由は書かれていない。**
**「前年の枠は今年に乗らない」は動いていない。**動いたのは「**だから空で渡す**」のほうである。

## 新しい結論

**テンプレートの条件入力 6 区画には、前回の値が初期値として入っている。担当者は今年の値に書き換えてから走らせる。**

- **値は [`src/sheet-layout.js`](../../../src/sheet-layout.js) の各区画の `initialRows` 1 か所**で、**コアが受け取る形**（`YYYY-MM-DD` ／ `HH:MM` ／ 数）で持つ
- **置くのはテンプレートを作るときだけ**（[`src/build-template.js`](../../../src/build-template.js) の `putInitialRows`）。
  **区画の入力欄に 1 セルでも中身があれば、その区画には置かない** — 書いた値を初期値で上書きしない
- **初期値のまま「生成」を押しても型の段で止まらない**（→ `src/input-types.test.mjs` の ⑤）。
  **型の読み方が動いて初期値が合わなくなったら、その検査が落ちる**
- **初期値は既定値ではない。**「連続して入る最小の長さ」を空けたときの `1:00`（`defaultMinRun`）とは別物である —
  **あちらは書かなかった年の値で、こちらはテンプレートに書いてある値である**
- **候補 F（前年のシフト表の流用）の却下は動いていない。**入ったのは条件であって、割り当ての表ではない
- **締切は今までどおり初期値を持たない**（Design Doc 6「締切だけは複製しない」）。締切は条件入力の区画に無い

## 影響

| 何が | どう動いたか |
| --- | --- |
| **5-1 の #1 の値の出どころ** | 「前年の値を既定にしない ◎」を「**テンプレートには前回の値が初期値として入っている。書き換えてから走らせる**」に書き直した。**「毎回入力する」は動いていない** |
| **6 の #1 の却下側** | 最後の一文（テンプレートが空であること自体が…）を、**空ではなくなったことと、それでも引き継ぎの却下は動かないこと**に書き直した。**却下の理由（氏名・学籍番号が 1 つのファイルに何年ぶんも残る）は動いていない** |
| **Design Doc 6** | 日ごとの営業 4 時刻の行を「毎回入力する。**テンプレートの初期値は前回の値で、書き換える**」に。締切の段落から「営業 4 時刻と同じ扱い」を外した（**締切を既定にしないのは動いていない**） |
| **テンプレートの組み立て** | 組み立ての記録に「「条件入力」の「…」に初期値を N 行置いた」が 6 行増えた |
| **失敗の形が 1 つ増えた** | **初期値を書き換え忘れると、前回の日付のまま走る。****型の段では止まらない**（前回の値は正しい形だからである）。**フォームの設問の題が 2025 年の日付になるので、フォームを作った時点で目に入る**（→ 4-1） |
| **実機** | **まだ見ていない。**`'2025-11-01'` ／ `'08:00'` ／ `'1:00'` をシートに置いたときに日付と時刻に読まれ、殻が同じ形に戻すことは、担当者が手で打つのと同じ経路のはずだが確かめていない |
