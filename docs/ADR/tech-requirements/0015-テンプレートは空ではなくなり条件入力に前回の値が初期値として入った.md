# ADR tech-requirements-0015 の要約

「テンプレートは空である」が崩れ、条件入力の 6 区画に前回の値が初期値として入った。担当者は今年の値に書き換えてから走らせる。
前年の値を既定にしないという判断は動いておらず、締切は初期値を持たない。書き換え忘れるとフォームの題が去年の日付になるので、そこで目に入る。
