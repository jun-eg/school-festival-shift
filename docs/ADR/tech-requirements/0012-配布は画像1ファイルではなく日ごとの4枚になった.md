# ADR tech-requirements-0012 の要約

配布は画像 1 ファイルではなく、日ごとの 4 枚になった。前回の配布物と同じ枚数で、入る側はその日の 1 枚を開けば自分の行が出る。
画像だけで配布が成立することは動いていない。
