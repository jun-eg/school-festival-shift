# ADR tech-requirements-0018 の要約

「配布はテンプレートのコピー」が、誰が何をどう渡すかを決めていなかった。使い終わったファイルをコピーすると、回答とフォームの紐付けが渡ってしまう。
本線は jun-eg が管理するテンプレートの copy リンクを README に置くこと、予備は前年の担当者が「来年用に空にする」を押したコピーを渡すことの 2 本になった。
