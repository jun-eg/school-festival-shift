# ADR tech-requirements-0011 の要約

取り消し（0017 が上書き）。「置ける人を使い切っていない」が外れ、1 枠も置かれない人は散らしの取りこぼしではなく規則 3 で決まっていた、と結論していた。
その部分は 0017 で上書きされた（帯を希望していない人も店に置けるようになった）。同時に決めた「まとまり」（1 時間未満の交代をやめる）と「散らし」（同点ならその日にまだ置いた枠が少ない人を先に）は有効のまま。
