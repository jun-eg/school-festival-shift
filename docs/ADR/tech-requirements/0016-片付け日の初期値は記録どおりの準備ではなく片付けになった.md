# ADR tech-requirements-0016 の要約

片付け日の初期値が、記録どおりの「準備」ではなく「片付け」になった。役割名だけ替えると需要が 0 枠の帯に効いて消えるので、営業時刻の行と組で替えた。
初期値は担当者が書き換える手本なので、記録どおりであることより手本として正しい形を採った。判定に使う入力は動いていない。
