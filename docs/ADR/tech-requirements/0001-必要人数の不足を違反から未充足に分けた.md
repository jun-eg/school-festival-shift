# ADR tech-requirements-0001 の要約

必要人数の不足が「違反」に数えられていて、M2 の合格の線が原理的に出ない形だった。
違反（置いた人が条件を破っている）と未充足（人数が足りない）に分け、M2 は違反 0 件かつ名指しされていない未充足 0 件とした。未充足そのものは 0 でなくてよい。
