# ADR tech-requirements-0003 の要約

準備・片付けの規則（午前だけなら準備、午後だけなら片付け）が、担当者の証言と前回の確定シフトで食い違った。
いったん規則から降ろした（0002。取り消し）が、担当者に確かめると意図した決め方は証言どおりで、前回の実行がそこまで届かなかっただけだった。
規則に戻し、午前と午後の境目は 12:00 で埋めた。両方に入っている人は削り忘れで、残り 2 種類の食い違いの理由は決まらないまま置いてある。
