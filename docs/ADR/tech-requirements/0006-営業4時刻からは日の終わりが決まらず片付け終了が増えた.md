# ADR tech-requirements-0006 の要約

営業 4 時刻からは日の終わりが決まらず、入力に「片付け終了」が増えて 5 時刻になった。
片付け開始を日の終わりと読むと、片付けの帯に枠が 1 つも生えない。設問の説明文の営業時間と前回の片付けの行が、日の終わりを示していた。
