# ADR tech-requirements-0014 の要約

「保護は生成シート 3 枚だけ」が崩れた。8 枚すべてに保護をかけ、かけ方は 2 つになった。
回答・検証結果・指標と、条件入力の入力欄の外は警告のみ。割り当ての 4 枚は持ち主だけが書ける。持ち主の手直しに確認は出ない。
