# ADR tech-requirements-0007 の要約

「前回の 5 時刻は記録に無い」が外れ、M2 の判定入力で準備帯が 0 枠になっていた。
確定シフトの行を日と役割で束ねると帯が読めるので、M2 の側はそこから算出した 5 時刻を使う。値は宣言に焼かず毎回算出する。M1 の側は 1 本の帯のままである。
