### 5-2. 友達欄は材料にしない

**フォームの項目としては残る**（聞かれ方を変えないため）が、**割り当ての材料にしない**（上流 6 スコープ外）。
**仕様としては「生成の入力に友達欄が現れない」である** — 5-1 の 6 種類に入っていないことで判定できる。

### 5-3. 手直しは入力に乗る — 再実行で消えない

**上流は「手直しが再実行で消えるのか残るのか」を決めていない。**
スコープ内 7（例外を直す）とスコープ内 9（やり直しが安い）が並んでいるだけである。
**ここは手段の話なので、この文書が決める。**

**決めたこと。手直しは残す。** 担当者が割り当てシートのセルを書き換えた所は**固定**として扱い、
**再実行は、固定を先に置いてから残りを生成する。**

**理由。**

- **消える形だと、達成条件 2 が構造的に成立しない。** 修正ループ（流す → 依頼が来る → 直す）も 5〜15 分 ◎ で回ることが条件だが、
  **消えるなら、締切後の提出 ◎（前回 6 人分）と配布後に届いた希望 ◎（前回 3 行）のたびに、それまでの手直しが全部やり直しになる。**
  2 周目以降の手数が初回を超えるので、**5 の #11 の「初回と同数」が回答の追加のたびに破れる**
- **固定が入力に乗るから残る。** 手直しが出力の上にあると、出力を作り直した瞬間に消える。
  **入力に積めば、再実行は「入力が 1 つ増えた状態でもう一度通す」ことと同じ**になり、#11 の数え方が変わらない

**固定が新しい入力と食い違ったときは、黙って外さない。**
（その人がその枠を希望から外した ／ `調理担当ですか？` の申告が変わった ／ 学年が変わった、など。
**締切後の提出 ◎ と出し直し ◎ が実際に起きる** ので、食い違いは起きうる。）

- **固定を優先して条件を破ることはしない** — 破ると M2 の「違反 0」が、担当者の手直しのせいで崩れる
- **固定を黙って外すこともしない** — 担当者が意図して置いた 1 手が、気づかないうちに消える
- **食い違った固定は、名指しで返す。**「満たせない枠は黙って埋めない」（上流 6 スコープ内 5）と同じ扱いである

**却下した形。**

| 形 | 却下の理由 |
| --- | --- |
| **手直しを出力の上に持つ（再実行で消える）** | 上記のとおり、達成条件 2 と 5 の #11 が回答の追加のたびに破れる |
| **前回の案全体を初期解にして、差分が最小になるように組み直す** | **どこが人の意思で、どこが機械の都合かが区別できない。**「担当者が動かした所は動かない」を保証できず、#11 の判定（動かしたセルが 1 つも戻っていないこと）が書けない |
| **再実行のたびに担当者に「残すか消すか」を聞く** | 聞く操作が毎回の手数に乗る。**締切後の提出のたびに増える**ので #11 が破れる |

### 5-4. 「違反」と「未充足」は別に数える

**上流は「違反が 0 の案が出る」と「満たせない枠は名指しで残す」を並べて書いている。**
この 2 つが両立するのは、**数える対象を分けたときだけ**である。分けないと、
人数が足りない枠がそのまま「必要人数の違反」になり、**違反 0 の案が永久に出ない。**

| | 何か | 生成はどう扱うか | M2 の合格の線 |
| --- | --- | --- | --- |
| **違反** | **置いた人が条件を破っている** — 検便 ◎（規則 5）・学年 ◎（規則 4）・希望の時間の外 ◎（規則 1）・準備／片付け（規則 3 の **①〜⑤**。**⑥ は入らない** → 下の但し書き）・**同じ人が同じ 30 分枠に二重に入っている** | **1 件も作らない。**破るくらいなら置かない | **0 件** |
| **未充足** | **人数が足りない** — 必要人数 ◎（5-1 の #2）・委員会の指定枠 ◎（規則 6） | **埋めずに残し、名指しで出す**（日・時間帯・役割・あと何人） | **名指しされていない未充足が 0 件**（未充足そのものは 0 でなくてよい） |

**規則 3 は、いまも全部は数えられない。****数えられる範囲が 1 つ増えた。**

- **①〜⑤（準備／片付けのどちらに入れるか）は数える。****この文書の △ 4 が閉じた**
  （①〜⑤ は規則のまま ◎、境目は `12:00` ◎ → 3 の規則 3・[`tech-requirements/0003`](ADR/tech-requirements/0003-準備と片付けの規則が降りた先から戻りM2の数えに入った.md)）。
  **2026-09-20 より前は、ここが数えから外れていた**
- **⑥（複数日で偏らせない）は、上流の △ 5 が決まるまで違反として数えない。**
  上流が「**決まるまで、MVP は並べるまでしかやらない**」（上流の △ 5）と決めているためで、**この文書で線を引かない**。
  **前回も線は引かれていなかった** ◎（「**時間が掛かるので公平性を担保出来なかった部分がある**」→ 9 の △ 5）

**上流の △ 5 が決まるまで ⑥ を、M2 の「違反 0」は含まない**、と読む。
**①〜⑤ が入ったことで、M2 の合格の線は動いている。****含まないことを隠さない**のがここの仕事である。

**前回の確定シフトに ①〜⑤ の違反があることは、ここに効かない。**
**数えるのは生成した案である。****前回の記録は M1 ① の入力**で、**見るのは型に乗るかだけ**である（→ 7・4-5 の「準備・片付けの入り方」の決着）。

**「同じ人が同じ枠に二重」は、上流にも記録にも明示が無い。**
**規則として足していない** — 3 の規則に行を作らず、**ここで「違反として数える」とだけ決めている。**
1 人が同じ 30 分に 2 つの役割をやれないことは**枠の定義から出る**ので、出どころを要する業務の規則ではない。

#### 未充足は、枠と役割ごとに 1 件である

**名指しに載せるのは 日・時間帯・役割・あと何人 である**（→ 上の表）。
**その 4 つを出すには、数える単位と、需要をどう枠に当てるかが要る。****ここが持つのは適用の網羅である**（→ 3）。

| | 決めたこと |
| --- | --- |
| **1 件の単位** | **(日・30 分枠・役割) 1 つにつき 1 件。****あと何人** ＝ その枠に要る人数 − **その枠に置いてある人の数**（**同じ人を 2 回数えない** — 二重は違反の側が数えるので、ここで 2 人ぶんに数えると未充足が隠れる） |
| **需要の切り方** | **必要人数（5-1 の #2）も、委員会の指定枠（規則 6）も、重なる 30 分枠すべてに効く。****日と時間帯を空けた行は全枠に効く**（→ 5-1 の #2） |
| **同じ枠に複数の行が効くとき** | **最大まで引き上げる。足し合わせない** |
| **どの枠にも重ならない需要** | **黙って落とさずに名指しして止まる**（日が「日ごとの営業時刻」に無い ／ 時間帯が営業時刻の外） |

**#2 を #4 と同じ向きに切るのは、#2 と #4 を同じ形式にした理由（→ 5-1）がそのまま効くからである。**
**切り方が違えば、指定枠だけが別の適用経路に戻る。****希望（規則 1 の ③）とだけ逆向きである** —
**希望は「完全に含まれる枠だけ」**（本人が居ない 15 分を割り当てないため）で、
**需要は「重なる枠すべて」**（**指定時間に人を欠かさない側に倒す**）である（→ 3 の境界値の表）。

**「引き上げる」の向きは規則 6 の ② が持っている。**足し合わせると、
**全枠に効く 1 行**（前回の必要人数 ◎ はこの形で書ける → 5-1 の #2）**と、時間帯を絞った 1 行が重なるだけで人数が倍になる。**
**広い 1 行を狭い 1 行が上書きする形が、担当者が書いたとおりの読み方である。**

**落とさずに止めるのは、合格の線がそこに乗っているからである。**
**「名指しされていない未充足が 0 件」（→ 上の表）は、数え落とした需要のぶんだけ嘘になる。**

### 5-5. 生成の適用の順序 — 何から埋め、どこに置かないか

**方式は 6 の #3 が決めている**（制約のきつい枠から順に埋める貪欲法 ＋ 局所的な入れ替え）。
**ここが持つのは適用の順序と、置き先の網羅だけである**（→ 3 の冒頭と同じ立て方）。
**規則は 3 が、違反と未充足の分け方は 5-4 が持つ。ここで規則を足さない。**

| | 決めたこと |
| --- | --- |
| **埋める順** | **(日・30 分枠・役割) 1 つを単位に、「置ける人 − 要る人数」が小さい順に埋める。**同点は 日 → 枠 → 役割（**担当者が需要を書いた順**。5-4 の未充足と同じ並びである）で、**並びは入力だけで決まる**（→ 6 の #3 の理由 ③） |
| **枠の中で誰を採るか** | **置いた数が少ない人から採り、同数なら候補に出てきた順**（＝ 取り込みが返した順）である。**⑥ の線ではない** — **均した量を測らず、順位も閾値も出さない**（→ 5-4 の但し書き・5 の #7） |
| **準備・片付けをどこに置くか** | **その日の帯の中だけに置く** — 準備は `準備開始`〜`調理開始`、片付けは `片付け開始`〜`片付け終了` である（**枠は時刻をまたがないので、その枠が帯の中かは枠の側で決まる** → 5-1 の #1）。**需要の残っている枠を先に取り、残っていなければ 1 枠だけ置く**（**規則 3 が要るのは「入っていること」**であって、帯を全部埋めることではない） |
| **置かないほうに倒す所** | **規則 3 を満たせなくなる置き方をしない。**その日の帯に、候補にあって空いている枠が 1 つも残らない人は、その枠に置かない（「**破るくらいなら置かない**」→ 5-4）。**帯を 1 枠も希望していない人は、その日に置けない** — 置けば規則 1 か規則 3 のどちらかが破れる。**その枠は未充足として名指しで残る**（→ 5 の #6「満たせない枠は黙って埋めない」） |
| **役割名を弾かない** | **需要に書かれた役割名にそのまま置く**（→ 規則 6 の ③。**5 役割 ◎ に無い名前でもよい**）。**規則 3・4・5 が当たるのは 3 の「規則が名指しする役割名」の 4 つだけ**で、**名前が合わない年は規則が当たらない**（→ 3。**弾くかどうかを決めるのは生成の側である**と書いてあった所である） |
| **氏名を埋めない** | **割り当ての `氏名` は空である。****型 #6 に氏名は無い**（→ 5-1）ので、埋めると **5 の #1（6 種類の外にある値を生成が参照しない）が破れる**。**埋めるとすれば回答シートを読む殻の側**であって、**コアではない。いまは埋めない** |
| **固定を積まない** | **5-3 の固定は、この段では積まない**（→ 8 の 11）。**受け取るが、いまは 1 行も見ない** |

## 6. 技術選定とトレードオフ

**記号（◎ / ○）を付けない。** ◎ は「観測して裏が取れた」の意味で、**選定は観測ではない。**
**却下した選択肢を消さない** — 選定が覆ったときに戻る先になる。
**2 が縛りである** — 実行形態で決めたことに反する選定は、ここで落ちる。
