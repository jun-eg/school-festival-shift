# 出典記号と (n/m) の数え方

`docs/journey/<立場>.md` で使う **出典記号**と **(n/m)** のルール。
**ここが原本である。** マップ側の「凡例：情報の出典」節にルールを書き写さない
（写すと、人を 1 人聞くたびに例外が各マップへ 1 行ずつ増える）。

マップ側の凡例節が持つのは、**そのマップ固有の事実だけ**（母数がいくつか / 実施日 / 逐語がどのファイルにあるか）。

## 出典記号

| 記号 | 意味 |
| --- | --- |
| ◎ | 裏が取れている（その立場のインタビューで確認した） |
| ○ | 伝聞・本人の推測（直接は観測していないが、証言としては出ている） |
| △ | 未検証（想像のまま。まだ誰にも確かめられていない） |

### （記録）

**◎ のうち、記憶ではなく一次記録（提出記録のタイムスタンプなど）で確認したものには `（記録）` を添える。**

- **記憶と記録が食い違ったときは記録を採る。**
- **自己申告と記録が食い違う場合は、記録を ◎（記録）として書き、自己申告は逐語として併記する。**

### 立場を区別する枝分かれ記号を作らない

**1 本 = 1 立場**なので、そのマップの ◎ はその立場の証言を指す。
`◎作` / `◎入` のような枝分かれ記号が要る状態は、**マップに別の立場が混ざっているサイン**である。

もう一方のマップから持ち込んだ事実には**記号を付けず**、`→ <他方の立場>:` と書いて相手のファイルを指す。

## (n/m) の数え方

◎ には **(n/m)** を添える。**1 人の証言を全員の話にしないため。**

### 母数 m

- **m は「その立場について本体の質問を聞いた人数」。** 立場ごとに数える
- **追い質問で取れたものも同じ母数で数える。** 聞いた相手が増えたわけではないので **m は増えない**
- **一部の人にしか送っていない問いは、送った人数を分母にする**（2 人にしか送っていない問いは `(n/2)`）
- **1 人にしか送っていない問いは `(1/1)` か、記号だけを付ける。** 本体の母数に混ぜない
- **兼務者は、その立場の本体の質問を聞いていなければ母数に数えない。**
  数えると `(1/4)` が「4 人に聞いて 1 人」に見え、**聞いていない人を非該当のように扱う**ことになる。
  兼務者の証言は ◎ で本文に入れてよいが、**(n/m) には数えない**（兼務の扱いは `SKILL.md` の手順 0）

### 分子 n

- **n は項目ごとに数え直す。** 母数だけ増やして n を据え置くと、**答えていない人を非該当に見せてしまう**
- **保留は非該当ではない。** ある人がその項目に答えていないなら、**n にも「非該当」にも数えない**

### 0 人のとき

**該当が 0 人の項目に `(0/m)` と書かない。** 「聞いた全員が否定した」と「誰も選ばなかった」は別物で、
記号だけでは区別できない。**何人が答えていないかを `注意:` 行（改善機会）に書く。**

## 逐語はマップに置かない

**◎ の裏付けになる逐語は `docs/interviews/<連番>-<立場>.md` の「回答」節が持つ**（`SKILL.md:109`）。
マップ側には**要約と記号だけ**を置き、原本はそちらへリンクする。

- 「その人が何者か・既存の誰と重なるか」も `docs/interviews/` 側の回答節の小見出しが持つ
  （`interview-questions/SKILL.md` の `<属性。何が散らせて何が重なっているか>`）。**マップに写さない**
- マップ側が持つのは **(n/m) の母数の決め方**と、**その証言をどこまで一般化してよいか**だけ
