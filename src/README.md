# src — 担当者のドライブで動くスクリプトの置き場

**ここにあるのは、担当者がコピーして使うスプレッドシートにバインドするスクリプトである。**
**データは [`data/`](../data/) が、数え直す手は [`scripts/`](../scripts/) が持つ。混ぜない。**

決めたことの出どころは [`docs/tech-requirements.md`](../docs/tech-requirements.md) である
（実行形態は **2**、シートの構成は **8 の 1**、列の中身は **5-1** と **5-4**）。
**ここに判断を新しく書かない。** 判断が動くなら要件定義書に戻して ADR を 1 本起こす。

| ファイル | 何を持つか |
| --- | --- |
| [`シート構成.js`](シート構成.js) | **5 枚のシートの定義だけ。** `SpreadsheetApp` を 1 度も掴まない（→ 6 の #8） |
| [`テンプレートを組み立てる.js`](テンプレートを組み立てる.js) | **殻。**定義どおりにシートを作り、見出しを置き、生成シートに保護をかける |
| [`メニュー.js`](メニュー.js) | **担当者が開いたときに出るメニュー 1 つ**（`onOpen`） |
| [`appsscript.json`](appsscript.json) | マニフェスト。**権限スコープはまだ書いていない**（→ [#139](https://github.com/jun-eg/school-festival-shift/issues/139)） |
| `*.test.mjs` | **手元で回す検査。**Apps Script には上げない（`.claspignore` で外してある） |
| [`実機で確かめた記録.md`](実機で確かめた記録.md) | **本物のスプレッドシートの上で見た結果。**実機でしか分からないものの名指しと、手元の検査 23 件との対応も持つ（→ [#167](https://github.com/jun-eg/school-festival-shift/issues/167)） |

## シートは 5 枚である

| シート | 何が乗るか | 担当者が書くか | 保護 |
| --- | --- | --- | --- |
| **条件入力** | 枠（日ごとの営業 4 時刻）／役割と必要人数／調理責任者の学年／委員会の指定枠／準備・片付けのルール（→ 5-1 の #1〜#5） | **書く** | かけない |
| **回答** | フォームの回答（→ 5-1 の #6）。**列は 4-1 の設問 9 つ ＋ タイムスタンプの転記である** | 書かない | かける |
| **割り当て** | 生成の結果。**担当者がセルを書き換えるのが仕様である**（→ 5-3） | **書く** | かけない |
| **検証結果** | 違反の一覧と、未充足の名指し。**種別の列で分ける**（→ 5-4） | 書かない | かける |
| **指標** | 人ごとの合計時間・シフト回数・準備回数。**順位付けも閾値も出さない**（→ 5 の #7） | 書かない | かける |

**入力の初期値を 1 つも置いていない。** テンプレートが空であること自体が
「**前年の値を既定にしない ◎**」（5-1 の #1）を満たしている（→ 6 の #1 の却下側）。
**形式は値ではないので、見出しのセルに注記（メモ）として付けてある。**

### 条件入力は、区画を横に並べる

**5 つの区画（5-1 の #1〜#5）を、列をずらして横に並べてある。**
1 行目が区画の見出し、2 行目が列名、3 行目から下が担当者の入力である。

| 列 | 区画 |
| --- | --- |
| A〜E | 日ごとの営業 4 時刻 |
| G〜K | 役割と必要人数 |
| M | 調理責任者の学年 |
| O〜S | 委員会の指定枠 |
| U〜V | 準備・片付けのルール |

**縦に積まないのは、行を足す操作が隣の区画を動かさないようにするためである。**
横に並べれば、**担当者は自分の区画の下の空き行に書き足すだけ**で済む
（**委員会の指定枠はフォーム作成後に来る ◎** ので、後から行を足す操作は必ず起きる → 規則 6 の ④）。
縦に積むと、途中の区画に 1 行足すだけで下の区画が全部ずれ、
「**行の削除・列の挿入**」（→ 2 の「止まる箇所」#8）と同じ壊れ方を担当者に踏ませることになる。

## 保護は「警告のみ」である

**生成シート 3 枚（回答・検証結果・指標）に保護をかけている。**
**ただし、かかり方は「警告のみ」である** — 書き換えようとすると確認が出るが、**押し切れば書ける。**

**締め出す形にできない。** 担当者が使うのは**自分のドライブにコピーした自分のファイル**で、
**Google スプレッドシートの保護は、ファイルの持ち主を締め出せない。**
編集者を絞る形（`removeEditors`）を書いても、持ち主である担当者には効かない。
**採れるいちばん強い形が「警告のみ」である。**

**これは 2 の「止まる箇所」#8 の予防のうち、片方だけが立っているということである。**
もう片方（**走る前に構造を検証し、崩れていれば名指しで出す**）は
[#138](https://github.com/jun-eg/school-festival-shift/issues/138) が引き受ける。
**復旧の側は動かない** — **テンプレートをもう 1 回コピーして条件を入れ直す**（→ 6 の #1 の理由 ⑤）。

## メニューは 1 つである

**担当者が開くと「シフト」メニューが出る。** 項目は
**2「担当者がやることの全部」の操作 3・7・9 と同じ名前**である（フォームを作る／生成／画像を書き出す）。
**担当者に新しい操作を増やしていないし、画面も 1 枚も作っていない**（→ 6 の #2）。

**中身はまだ入っていない。** 押すと「**まだ作っていない（issue #…）**」と名指しで言う
（[#144](https://github.com/jun-eg/school-festival-shift/issues/144)／[#151](https://github.com/jun-eg/school-festival-shift/issues/151)／[#157](https://github.com/jun-eg/school-festival-shift/issues/157) が入れる）。
**黙って走らせない。**

**`テンプレートを組み立てる` はメニューに出していない。**
**走らせるのはテンプレートを用意する側で、担当者ではない**（2 の一覧に無い操作を増やさないため）。

## テンプレートの作り方

**担当者に要求する操作ではない。** テンプレートを 1 つ作るときに、用意する側が 1 回だけやる。

1. Google ドライブで**スプレッドシートを 1 つ**作る
2. **拡張機能 → Apps Script** を開く
3. `src/` の **`.js` 3 つ**を、同じ名前のファイルとして貼る（エディタ上では `.gs` になる）
4. **プロジェクトの設定 →「`appsscript.json` マニフェスト ファイルをエディタで表示する」**を入れ、
   [`appsscript.json`](appsscript.json) の中身を写す
5. エディタで **`テンプレートを組み立てる` を実行**する。**初回の権限承認はここで通る**
   （どの画面が出るかを記録するのは [#139](https://github.com/jun-eg/school-festival-shift/issues/139)）
6. スプレッドシートを開き直し、**メニュー「シフト」が出ること**と、**5 枚が並んでいること**を見る
7. そのファイルを**コピーして配る形**にする（**コピーでスクリプトが渡るかを確かめるのは
   [#136](https://github.com/jun-eg/school-festival-shift/issues/136)** → 6-1 の #3）

**clasp（`clasp push`）でも入る。** ただし `.clasp.json` は**スプレッドシートごとに違う**ので、
リポジトリに入れない（`.gitignore` に置いてある）。**clasp の導入を担当者に要求することは無い。**

## 確かめ方

```
node src/シート構成.test.mjs
node src/テンプレートを組み立てる.test.mjs
```

**依存はゼロである**（Node の標準だけを使う）。**何も書き換えない。**
全件一致なら終了コード 0、1 つでも外れたら 1 で落ちる。

| 検査 | 何を見るか |
| --- | --- |
| [`シート構成.test.mjs`](シート構成.test.mjs) | 5 枚・担当者が書く側・保護する側・区画・列名。**回答シートの列は [`data/前回の希望データ-モック.csv`](../data/前回の希望データ-モック.csv) の見出しと突き合わせる** |
| [`テンプレートを組み立てる.test.mjs`](テンプレートを組み立てる.test.mjs) | **偽のスプレッドシートの上で組み立てを走らせる。**5 枚できるか／保護が 3 枚に警告のみでかかるか／**2 回走らせても形が変わらないか**／**見出しが違うときに上書きせず名指しで止まるか** |

**この 2 つで分かるのは、手元で回る範囲だけである。**
**実機でしか分からないものの名指しと、実機で見た結果は
[`実機で確かめた記録.md`](実機で確かめた記録.md) が持つ。ここに二重に書かない。**
