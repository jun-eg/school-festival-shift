# 実機で確かめた記録 — `src/` を本物のスプレッドシートに載せる

**実装者の道具である。** この文書は**担当者の操作**（→ [`docs/tech-requirements.md`](../docs/tech-requirements.md) 2「担当者がやることの全部」の 10 行）**も、画面の枚数も 1 つも増やさない。**

**載せ方そのものは [`README.md`](README.md) の「テンプレートの作り方」が持つ。ここに二重に書かない。**

| ここが持つもの | |
| --- | --- |
| **手元で分かる範囲と、実機でしか分からない範囲の線** | 同じことを二重に数えないため |
| **実機で見る項目**と、**確かめた／確かめていないの別** | |
| **走らせた 1 回ごとの記録** | 通った／通らなかった・外れた前提 |
| **確認に使うファイルの規約** | 実データを 1 行も入れない・画像の置き場 |

**判定はここが持たない。** 下の表の 5 は [#136](https://github.com/jun-eg/school-festival-shift/issues/136) が、
初回承認の画面は [#139](https://github.com/jun-eg/school-festival-shift/issues/139) が、
担当者が自力で通せるかは [#160](https://github.com/jun-eg/school-festival-shift/issues/160) が持つ。
**ここが持つのは、判定を載せる土台だけである。**
