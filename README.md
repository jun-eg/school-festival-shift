# 学祭シフトの引き継ぎ手順

### 1. テンプレートファイルをコピーする

**[こちら](https://docs.google.com/spreadsheets/d/1WcbUczLpBnBjQbhmIAGGQUYgsnuphu5Ih2ga9_8zaNs/copy) から Google スプレッドシートをコピーします。**
コピーはご自身の Google ドライブに保存されるため、お手数ですが Google へのログインをお願いします。

1. **アカウントを選択します。** 個人・大学のどちらのアカウントでも構いません。使い慣れている方を選んでください。

   <img width="500" alt="アカウントを選択してください" src="docs/画面の記録/0012-アカウントを選択してください.png">

2. **「コピーを作成」を押します。** 「添付の Apps Script ファイルと機能もコピーされます」と出ますが、そのまま進めて構いません。

   <img width="500" alt="ドキュメントのコピー" src="docs/画面の記録/0013-ドキュメントのコピー.png">

3. **「セキュリティの制限」が出たら「OK」を押します。**

   <img width="300" alt="セキュリティの制限" src="docs/画面の記録/0014-セキュリティの制限.png">

4. **画面左上のタイトル（「コピー 〜 学祭シフト」）を押し、好きなファイル名に変えます。**

   <img width="500" alt="コピーが開いた" src="docs/画面の記録/0015-コピーが開いた.png">

5. **タイトルが変われば、テンプレートファイルのコピーは完了です。**

   <img width="500" alt="名前を変えた後" src="docs/画面の記録/0016-名前を変えた後.png">

### 2. 条件を入力する

**「条件入力」シートに入れた条件をもとに、シフトを作ります。**
**太字**の項目以外は、基本的に初期値のままで構いません。

1. **学祭の日付**と、**準備開始**・**調理開始**・**調理終了**・**片付け開始**・**片付け終了**の時刻を、今年の予定に合わせて変えます。初期値と同じ形で入力してください。

   <img width="500" alt="日ごとの営業時刻" src="docs/画面の記録/0017-条件入力-日ごとの営業時刻.png">

2. 役割ごとの必要人数を決めます。**準備**と**片付け**は、日ごとに人数を決められます。

   <img width="500" alt="役割と必要人数" src="docs/画面の記録/0018-条件入力-役割と必要人数.png">

3. 調理責任者になれる学年を決めます。

   <img width="143" alt="調理責任者の学年" src="docs/画面の記録/0019-条件入力-調理責任者の学年.png">

4. **委員会の指定枠**を入れます（例: クリーンパトロール）。

   <img width="500" alt="委員会の指定枠" src="docs/画面の記録/0020-条件入力-委員会の指定枠.png">

5. 午前と午後の境界の時刻を決めます。準備に入っているのに午前の役割が無い、といった割り当てを避けるために使います。

   <img width="261" alt="午前と午後の境界" src="docs/画面の記録/0021-条件入力-午前と午後の境界.png">

6. シフト 1 回ぶんの最小時間を決めます。

   <img width="259" alt="連続して入る最小時間" src="docs/画面の記録/0022-条件入力-連続して入る最小時間.png">

7. 9〜10 行目は空のままで構いません。次の「3. フォームを作る」でフォームを作ると、ここに URL が自動で入ります。**これで条件の入力は完了です。**

   <img width="500" alt="フォームの URL 欄" src="docs/画面の記録/0023-条件入力-フォームのURL欄.png">

### 3. フォームを作る

1. **画面上部のメニューの「シフト」を押します。**

   <img width="500" alt="メニューのシフト" src="docs/画面の記録/0024-メニューのシフト.png">

2. **「フォームを作る」を押します。**

   <img width="500" alt="フォームを作る" src="docs/画面の記録/0025-フォームを作る.png">

3. **初めてのときは「認証が必要です」と出るので、「OK」を押します。**

   <img width="500" alt="認証が必要です" src="docs/画面の記録/0026-認証が必要です.png">

4. **「すべて選択」にチェックを入れ、「続行」を押します。**

   <img width="500" alt="アクセスを求めています" src="docs/画面の記録/0027-アクセスを求めています-すべて選択.png">

5. **調理名簿の画像を選び、「フォームを作る」を押します。** 作り終わるまで 30 秒〜1 分ほどかかります。

   <img width="500" alt="調理名簿の画像を選択" src="docs/画面の記録/0028-調理名簿の画像を選択.png">

6. **「フォーム作成が完了しました！！」と出れば、フォームの作成は完了です。**

   <img width="500" alt="フォーム作成が完了しました" src="docs/画面の記録/0029-フォーム作成が完了しました.png">

7. **配布用の URL を、サークルに共有します**（LINE グループのノートなど）。URL は「条件入力」シートの 9 行目にも自動で入っています。

   <img width="500" alt="フォームの URL が入った" src="docs/画面の記録/0030-条件入力-フォームのURLが入った.png">
