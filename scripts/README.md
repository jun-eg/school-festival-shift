# scripts — 数え直す手の置き場

**ここにあるのは、データから数え直して宣言と突き合わせる手である。** 実装（GAS）ではない。
**データそのものは [`data/`](../data/) が持つ。混ぜない。**

## 件数の検算

```
node scripts/件数の検算.mjs
```

**依存はゼロである**（Node の標準だけを使う）。**何も書き換えない。読むだけである。**
**全件一致なら終了コード 0、1 つでも外れたら 1 で落ちる。**

| | |
| --- | --- |
| **入力** | [`data/`](../data/) の 5 本だけ（確定シフトのモック 4 本 ＋ 希望データのモック 1 本） |
| **期待値** | [`件数の期待値.json`](件数の期待値.json)。**ここが原本である。スクリプトは期待値を持たない** |
| **見るもの** | ① data から数え直した値が期待値と一致するか ② その数字が本文に載っているか ③ 数え方の宣言を頭に出す |

**本文の側は、数字が載っていることしか見ない。解析はしない。**
そのかわり、**本文の数字が書き換わったのに期待値を直し忘れた場合も落ちる** —
[`docs/tech-requirements.md`](../docs/tech-requirements.md) と [`data/前回の確定シフト.md`](../data/前回の確定シフト.md) が
同じ数字を二重に持っていることへの見張りを兼ねる。

## いつ走らせるか

**手で 1 コマンドである。CI にも hook にも乗せていない**（実装が入って CI ができたら、そのときに乗せる
→ [`docs/tech-requirements.md`](../docs/tech-requirements.md) 8）。

- [`data/`](../data/) を触った PR
- [`docs/tech-requirements.md`](../docs/tech-requirements.md) の **4-5・7** か
  [`data/前回の確定シフト.md`](../data/前回の確定シフト.md) の**件数を触った PR**

**走らせたら、出力を PR に貼る。**

## 数えた結果が外れたら

**データと本文のどちらが正かは、この手は決めない。** 落ちたことだけを言う。
**期待値を書き換えて通すのは最後である** — 先に「data と本文のどちらが動いたのか」を見る。

## 数え方を足すとき

**期待値と数え方は [`件数の期待値.json`](件数の期待値.json) に書く。スクリプトの中に数字を書かない。**
**宣言しないと数えられないもの**（畳み方・重なりの定義・一致の定義）は、
**決めた側と、なぜ宣言が要るかを `数え方` に足す**
（→ [`.claude/skills/tech-requirements/SKILL.md`](../.claude/skills/tech-requirements/SKILL.md) 手順 7）。
